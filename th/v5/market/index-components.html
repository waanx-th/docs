ดูองค์ประกอบของราคาดัชนี

คำขอ HTTP​

GET/v5/market/index-price-components

พารามิเตอร์คำขอ​

พารามิเตอร์จำเป็นประเภทคำอธิบาย
indexNametruestringชื่อดัชนี เช่น BTCUSDT

พารามิเตอร์การตอบกลับ​

พารามิเตอร์ประเภทคำอธิบาย
indexNamestringชื่อของดัชนี (เช่น BTCUSDT)
lastPricestringราคาล่าสุดของดัชนี
updateTimestringประทับเวลาของการอัปเดตครั้งล่าสุด หน่วยมิลลิวินาที
componentsarrayรายการองค์ประกอบที่ใช้คำนวณราคาดัชนี
> exchangestringชื่อของกระดานเทรด
> spotPairstringคู่เทรดสปอตบนกระดานเทรดนั้น (เช่น BTCUSDT)
> equivalentPricestringราคาเทียบเท่า
> multiplierstringตัวคูณที่ใช้กับราคาขององค์ประกอบ
> pricestringราคาที่เกิดขึ้นจริง
> weightstringน้ำหนักในการคำนวณดัชนี

  • HTTP
  • Go
  • Java
  • Node.js
