ดึงประวัติการ Convert

คืนราคาเสนอที่ได้รับการยืนยันทั้งหมด

ข้อมูล

ตั้งแต่วันที่ 10 กันยายน 2025 เป็นต้นไป การ convert ที่ทำผ่านหน้าเว็บสามารถเรียกดูผ่าน API นี้ได้เช่นกัน

คำขอ HTTP​

GET/v5/asset/exchange/query-convert-history

พารามิเตอร์คำขอ​

พารามิเตอร์จำเป็นประเภทคำอธิบาย
accountTypefalsestringประเภทวอลเล็ต
eb_convert_funding: บันทึกการ convert ของ funding wallet ผ่าน API
eb_convert_uta: บันทึกการ convert ของ uta wallet ผ่าน API
funding: การ convert คริปโตทั่วไปผ่านเว็บ/แอป
funding_fiat: การ convert เงินสกุลปกติกับคริปโตผ่านเว็บ/แอป
funding_fbtc_convert: การ convert FBTC เป็น BTC ผ่านเว็บ/แอป
funding_block_trade: การ convert แบบ block trade ผ่านเว็บ/แอป
  • รองรับการส่งหลายประเภท โดยคั่นด้วยเครื่องหมายจุลภาค เช่น eb_convert_funding,eb_convert_uta
  • หากไม่ระบุ จะคืนข้อมูลของวอลเล็ตทุกประเภท
indexfalseintegerหมายเลขหน้า
  • เริ่มจาก 1
  • ค่าเริ่มต้นคือหน้าที่ 1
    • limitfalseintegerจำนวนรายการต่อหน้า
  • ค่าเริ่มต้น 20 รายการ
  • สูงสุด 100 รายการ หากเกิน 100 จะคืน 100

    • พารามิเตอร์การตอบกลับ​

    พารามิเตอร์ประเภทคำอธิบาย
    listarray<object>อาร์เรย์ของราคาเสนอ
    > accountTypestringประเภทวอลเล็ต
    eb_convert_funding: บันทึกการ convert ของ funding wallet ผ่าน API
    eb_convert_uta: บันทึกการ convert ของ uta wallet ผ่าน API
    funding: การ convert คริปโตทั่วไปผ่านเว็บ/แอป
    funding_fiat: การ convert เงินสกุลปกติกับคริปโตผ่านเว็บ/แอป
    funding_fbtc_convert: การ convert FBTC เป็น BTC ผ่านเว็บ/แอป
    funding_block_trade: การ convert แบบ block trade ผ่านเว็บ/แอป
    > exchangeTxIdstringID ธุรกรรมการแลกเปลี่ยน เหมือนกับ ID ธุรกรรมของราคาเสนอ
    > userIdstringID ผู้ใช้
    > fromCoinstringเหรียญต้นทาง
    > fromCoinTypestringประเภทเหรียญต้นทาง crypto
    > toCoinstringเหรียญปลายทาง
    > toCoinTypestringประเภทเหรียญปลายทาง crypto
    > fromAmountstringจำนวนเหรียญต้นทาง (จำนวนที่ต้องการขาย)
    > toAmountstringจำนวนเหรียญปลายทาง (จำนวนที่จะซื้อได้ตามอัตราแลกเปลี่ยน)
    > exchangeStatusstringสถานะการแลกเปลี่ยน
    • init
    • processing
    • success
    • failure
    > extInfoobject
    >> paramTypestringฟิลด์นี้จะแสดงเมื่อคุณส่งค่านี้ใน ขอราคาเสนอ
    >> paramValuestringฟิลด์นี้จะแสดงเมื่อคุณส่งค่านี้ใน ขอราคาเสนอ
    > convertRatestringอัตราแลกเปลี่ยน
    > createdAtstringเวลาที่สร้างราคาเสนอ
