พารามิเตอร์คำขอ​

พารามิเตอร์จำเป็นประเภทคำอธิบาย
reqIdfalsestringใช้ระบุความไม่ซ้ำกันของคำขอ เมื่อส่งค่านี้มา การตอบกลับจะคืนค่านี้ให้ ความยาวต้องไม่เกิน 36 อักขระ
  • หากส่งมา ค่านี้ต้องไม่ซ้ำกัน มิฉะนั้นคุณจะได้รับ "20006"
headertrueobjectเฮดเดอร์ของคำขอ
> X-BAPI-TIMESTAMPtruestringประทับเวลาปัจจุบัน
> X-BAPI-RECV-WINDOWfalsestringค่าเริ่มต้นคือ 5000(ms) คำขอจะถูกปฏิเสธเมื่อไม่เป็นไปตามกฎนี้: WaanX_server_time - X-BAPI-RECV-WINDOW <= X-BAPI-TIMESTAMP < WaanX_server_time + 1000
> Refererfalsestringตัวระบุ referer สำหรับผู้ใช้ API broker
optruestringประเภท op
  • order.create: สร้างคำสั่งซื้อขาย
  • order.amend: แก้ไขคำสั่งซื้อขาย
  • order.cancel: ยกเลิกคำสั่งซื้อขาย
argstruearray&ltobject&gtอาร์เรย์ args ปัจจุบันรองรับเพียงหนึ่งรายการเท่านั้น
  • order.create: ดูคำขอสร้างคำสั่งซื้อขาย
  • order.amend: ดูคำขอแก้ไขคำสั่งซื้อขาย
  • order.cancel: ดูคำขอยกเลิกคำสั่งซื้อขาย

พารามิเตอร์การตอบกลับ​

พารามิเตอร์ประเภทคำอธิบาย
reqIdstring
  • หากส่งค่านี้มาในคำขอ ก็จะถูกคืนค่าในการตอบกลับ
  • หากไม่ได้ส่งมา ก็จะไม่ถูกคืนค่าในการตอบกลับ
retCodeinteger
  • 0: สำเร็จ
  • 10403: เกินการจำกัดอัตราการเรียกของ IP โดยจำกัดที่ 3000 คำขอต่อวินาทีต่อหนึ่ง IP
  • 10404: 1. ไม่พบประเภท op; 2. category ไม่ถูกต้องหรือไม่รองรับ
  • 10429: การป้องกันความถี่ในระดับระบบ
  • 20006: reqId ซ้ำกัน
  • 10016: 1. เกิดข้อผิดพลาดภายในเซิร์ฟเวอร์; 2. บริการกำลังรีสตาร์ต
  • 10019: บริการเทรดผ่าน ws กำลังรีสตาร์ต จึงไม่รับคำขอใหม่ แต่คำขอที่กำลังดำเนินการอยู่จะไม่ได้รับผลกระทบ คุณสามารถสร้างการเชื่อมต่อใหม่เพื่อให้ถูกกำหนดเส้นทางไปยังบริการที่ทำงานปกติได้
retMsgstring
  • OK
  • ""
  • ข้อความข้อผิดพลาด
opstringประเภท op
dataobjectข้อมูลทางธุรกิจ เหมือนกับ result ในการตอบกลับของ rest api
  • order.create: ดูการตอบกลับของการสร้างคำสั่งซื้อขาย
  • order.amend: ดูการตอบกลับของการแก้ไขคำสั่งซื้อขาย
  • order.cancel: ดูการตอบกลับของการยกเลิกคำสั่งซื้อขาย
retExtInfoobjectเป็นอ็อบเจกต์ว่างเสมอ
headerobjectข้อมูลเฮดเดอร์
> TraceIdstringรหัสติดตาม ใช้ติดตามเส้นทางของคำขอ
> Timenowstringประทับเวลาปัจจุบัน
> X-Bapi-Limitstringการจำกัดอัตราการเรียกทั้งหมดของบัญชีปัจจุบันสำหรับประเภท op นี้
> X-Bapi-Limit-Statusstringการจำกัดอัตราการเรียกที่เหลือของบัญชีปัจจุบันสำหรับประเภท op นี้
> X-Bapi-Limit-Reset-Timestampstringประทับเวลาที่ระบุว่าการจำกัดคำขอของคุณจะรีเซ็ตเมื่อใด หากคุณใช้เกินการจำกัดอัตราการเรียกแล้ว หากไม่เกิน ค่านี้ก็เป็นเพียงประทับเวลาปัจจุบัน (ซึ่งอาจไม่ตรงกับ timeNow เป๊ะ ๆ)
connIdstringรหัสการเชื่อมต่อ ซึ่งเป็นรหัสที่ไม่ซ้ำกันของการเชื่อมต่อนั้น
ข้อมูล

การตอบรับ (ack) ของคำขอสร้าง/แก้ไข/ยกเลิกคำสั่งซื้อขายบ่งบอกว่าคำขอถูกรับไว้เรียบร้อยแล้ว โปรดใช้สตรีมคำสั่งซื้อขายผ่าน websocket เพื่อยืนยันสถานะของคำสั่งซื้อขาย

ตัวอย่างคำขอ​

{
    "reqId": "test-005",
    "header": {
        "X-BAPI-TIMESTAMP": "1711001595207",
        "X-BAPI-RECV-WINDOW": "8000",
        "Referer": "bot-001" // for api broker
    },
    "op": "order.create",
    "args": [
        {
            "symbol": "ETHUSDT",
            "side": "Buy",
            "orderType": "Limit",
            "qty": "0.2",
            "price": "2800",
            "category": "spot",
            "timeInForce": "PostOnly"
        }
    ]
}

    "reqId": "test-005",
    "retCode": 0,

    "data": {
        "orderId": "a4c1718e-fe53-4659-a118-1f6ecce04ad9",
        "orderLinkId": ""
    },
    "retExtInfo": {},
    "header": {
        "X-Bapi-Limit": "10",
        "X-Bapi-Limit-Status": "9",
        "X-Bapi-Limit-Reset-Timestamp": "1711001595208",
        "Traceid": "38b7977b430f9bd228f4b19724794dfd",

    },
    "connId": "cnt5leec0hvan15eukcg-2v"
}

สร้าง/แก้ไข/ยกเลิกคำสั่งซื้อขายแบบกลุ่ม​

ข้อมูล
  • สามารถสร้างคำสั่งซื้อขายได้สูงสุด 10 รายการ (สปอต) ต่อหนึ่งคำขอ รายการข้อมูลที่คืนค่ามาจะถูกแบ่งเป็นสองรายการ รายการแรกระบุว่าการสร้างคำสั่งซื้อขายสำเร็จหรือไม่ และรายการที่สองแสดงรายละเอียดข้อมูลของคำสั่งซื้อขายที่สร้างขึ้น โครงสร้างของทั้งสองรายการสอดคล้องกันทั้งหมด
  • คำอธิบายการจำกัดอัตราการเรียกของสปอต โปรดดูกฎการจำกัดอัตราการเรียก
  • การจำกัดอัตราการเรียกระดับบัญชีถูกใช้ร่วมกันระหว่างคำสั่งซื้อขายแบบกลุ่มผ่าน websocket และ http
  • การตอบรับคำขอสร้าง/แก้ไข/ยกเลิกคำสั่งซื้อขายแบบกลุ่มบ่งบอกว่าคำขอถูกรับไว้เรียบร้อยแล้ว คำขอนี้ทำงานแบบอะซิงโครนัส ดังนั้นโปรดใช้ websocket เพื่อยืนยันสถานะของคำสั่งซื้อขาย
