แก้ไขคีย์ API ของบัญชีย่อย

แก้ไขการตั้งค่าของคีย์ API ของบัญชีย่อย โดยใช้คีย์ API ของบัญชีย่อยที่ต้องการแก้ไขในการเรียกเอนด์พอยต์นี้ หรือใช้คีย์ API ของ บัญชีหลักเพื่อจัดการคีย์ API ของบัญชีย่อยที่อยู่ภายใต้

เคล็ดลับ

คีย์ API ต้องมีสิทธิ์อย่างใดอย่างหนึ่งด้านล่างนี้จึงจะเรียกเอนด์พอยต์นี้ได้

  • คีย์ API ของบัญชีย่อย: "Account Transfer", "Sub Member Transfer"
  • คีย์ API ของบัญชีหลัก: "Account Transfer", "Sub Member Transfer", "Withdrawal"

คำขอ HTTP​

POST/v5/user/update-sub-api

พารามิเตอร์คำขอ​

พารามิเตอร์จำเป็นประเภทคำอธิบาย
apikeyfalsestringคีย์ API ของบัญชีย่อย
  • คุณต้องส่งพารามิเตอร์นี้เมื่อใช้บัญชีหลักจัดการการตั้งค่าคีย์ API ของบัญชีย่อย
  • หากคุณใช้คีย์ API ของ UID บัญชีย่อยนั้นเรียกเอนด์พอยต์นี้ จะส่งพารามิเตอร์ apikey มาไม่ได้ มิฉะนั้นจะเกิดข้อผิดพลาด
readOnlyfalseinteger0 (default): อ่านและเขียน 1: อ่านเท่านั้น
ipsfalsestringกำหนด IP ที่ต้องการผูก ตัวอย่าง: "192.168.0.1,192.168.0.2"หมายเหตุ:
  • ไม่ส่ง ips มา หรือส่งเป็น "*" หมายถึงไม่ผูก IP
  • คีย์ API ที่ไม่ได้ผูก IP จะใช้งานไม่ได้หลังจาก 90 วัน
  • คีย์ API จะใช้งานไม่ได้หลังจาก 7 วัน เมื่อมีการเปลี่ยนรหัสผ่านของบัญชี
permissionsfalseObjectเลือกประเภทของสิทธิ์ ไม่ต้องส่งพารามิเตอร์นี้มาหากคุณไม่ต้องการเปลี่ยนสิทธิ์
> Spotfalsearrayการเทรดสปอต ["SpotTrade"]
> Walletfalsearrayกระเป๋าเงิน ["AccountTransfer", "SubMemberTransferList"]
หมายเหตุ: ยังไม่รองรับบัญชีแบบ fund custodial
> Exchangefalsearrayการแปลงสกุลเงิน ["ExchangeHistory"]
> Earnfalsearrayผลิตภัณฑ์ Earn ["Earn"]

พารามิเตอร์การตอบกลับ​

พารามิเตอร์ประเภทคำอธิบาย
idstringID ที่ไม่ซ้ำกัน ใช้ภายในระบบ
notestringหมายเหตุ
apiKeystringคีย์ API
readOnlyinteger0: อ่านและเขียน 1: อ่านเท่านั้น
secretstringเป็น "" เสมอ
permissionsObjectประเภทของสิทธิ์
> Spotarrayสิทธิ์ของสปอต
> Walletarrayสิทธิ์ของกระเป๋าเงิน
> Exchangearrayสิทธิ์ของการแปลงสกุลเงิน
> Earnarrayสิทธิ์ของ Earn
> BlockTradearrayไม่ใช้กับบัญชีย่อย จะเป็น [] เสมอ
> Affiliatearrayไม่ใช้กับบัญชีย่อย จะเป็น [] เสมอ
> FiatP2Parrayไม่ใช้กับบัญชีย่อย จะเป็น [] เสมอ
> FiatConvertBrokerarrayไม่ใช้กับบัญชีย่อย จะเป็น [] เสมอ
> NFTarrayเลิกใช้งานแล้ว, จะเป็น [] เสมอ
> CopyTradingarrayเลิกใช้งานแล้ว, จะเป็น [] เสมอ
ipsarrayIP ที่ผูกไว้
