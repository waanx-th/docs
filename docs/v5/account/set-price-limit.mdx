You can configure how the system behaves when your limit order price exceeds the highest bid or lowest ask price.
You can query your current configuration with [Get Trade Behaviour Setting](/v5/account/get-user-setting-config).
Learn more about the [price limit](https://support.waanx.com/en/support/home) in the help centre.

---

Where x% is [priceLimitRatioX](/v5/market/instrument); and y% is the [priceLimitRatioY](/v5/market/instrument):

* **Maximum buy price**: *Min[Max(Index Price, Index Price × (1 + x%) + 2-Minute Average Premium), Index Price × (1 + y%)]*
* **Minimum sell price**: *Max[Min(Index Price, Index Price × (1 – x%) + 2-Minute Average Premium), Index Price × (1 – y%)]*

:::info Default Setting
**modifyEnable = false.** If the order price exceeds the limit, the system rejects the request. <br/>
Corresponds to [Get Limit Price Behaviour](./get-user-setting-config), where **lpaSpot = false**
:::

### HTTP Request
<APIEndpoint method="POST" url="/v5/account/set-limit-px-action" />

### Request Parameters
| Parameter | Required | Type | Comments|
|:----- |:-------|:-----|------ |
|category |**true** |string |`spot`|
|modifyEnable |**true** |boolean |`true`: allow the system to modify the order price<br/>`false`: reject your order request|

### Response Parameters
None
