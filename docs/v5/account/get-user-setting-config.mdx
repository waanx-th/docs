You can get configuration how the system behaves when your limit order price exceeds the highest bid or lowest ask price. The response also includes whether [Delta Neutral mode](/v5/account/set-delta-mode) is enabled.

---

Where x% is [priceLimitRatioX](/v5/market/instrument); and y% is the [priceLimitRatioY](/v5/market/instrument):

* **Maximum buy price**: *Min[Max(Index Price, Index Price × (1 + x%) + 2-Minute Average Premium), Index Price × (1 + y%)]*
* **Minimum sell price**: *Max[Min(Index Price, Index Price × (1 – x%) + 2-Minute Average Premium), Index Price × (1 – y%)]*

:::info Default Setting
**lpaSpot = false.** If the order price exceeds the limit, the system rejects the request.
:::

### HTTP Request
<APIEndpoint method="GET" url="/v5/account/user-setting-config" />

### Request Parameters
None

### Response Parameters
| Parameter | Type | Comments|
|:----- |:-----|----- |
|result |array |Object |
|> lpaSpot |boolean |<ul><li>`true`: If the order price exceeds the limit, the system will automatically adjust the price to the nearest allowed price</li><li>`false`: If the order price exceeds the limit, the system rejects the request.</li></ul>|
|> deltaEnable |boolean |Whether [Delta Neutral mode](/v5/account/set-delta-mode) is enabled. `true`: enabled; `false`: disabled|
|> smsef |boolean |Whether Spot MNT fee deduction is enabled. `true`: enabled; `false`: disabled|
|> smpType |integer |User SMP (Self-Match Prevention) type configuration. `0`: Default, does not trigger self-match prevention; `1`: Cancel Taker order when self-match detected; `2`: Cancel Maker order when self-match detected; `3`: Cancel both Maker and Taker orders when self-match detected|
