## Overview
This draft is being aligned to the WaanX Thailand product scope. Phase 1 focuses on
custody, fiat deposits and withdrawals, THB and USDT Spot, and spot-only conversion
(including small balances). Product scope does not by itself confirm the availability
of any individual Open API endpoint.

## API Paths
V5 API paths group operations into market data, orders, accounts and assets.

> &#123;host&#125;/&#123;version&#125;/&#123;product&#125;/&#123;module&#125;<br/>
Example: api.waanx.com/v5/market/recent-trade

|Address Segment  | Description |
|:----- |-------|
|v5/market/|Candlestick, orderbook, ticker, platform transaction data, underlying financial rules, risk control rules|
|v5/order/|Order management|
|v5/account/|Account information and fee rates|
|v5/asset/|Operations across multiple accounts – asset management, fund management, etc.|
