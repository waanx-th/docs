For spot trading order price limit, refer to <a href="https://waanx.com/en/gb/announcements">announcement</a><br/>

### HTTP Request
<APIEndpoint method="GET" url="/v5/market/price-limit" />

### Request Parameters
| Parameter | Required | Type | Comments|
|:----- |:-------|:-----|------|
|[category](../enum#category) |false |string |Product type. `spot` <ul><li>When `category` is not passed, use `spot` by default</li></ul>|
|[symbol](../enum#symbol) |<b>true</b> |string |Symbol name, like `BTCUSDT`, uppercase only|

### Response Parameters
| Parameter | Type | Comments|
|:----- |:-----|----- |
|symbol |string |Symbol name |
|buyLmt |string |Highest Bid Price |
|sellLmt |string |Lowest Ask Price |
|ts |string |timestamp in milliseconds |
