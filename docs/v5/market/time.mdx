### HTTP Request
<APIEndpoint method="GET" url="/v5/market/time" />

### Request Parameters
None

### Response Parameters
| Parameter | Type | Comments|
|:----- |:-----|----- |
| timeSecond | string | WaanX server timestamp (sec)  |
| timeNano | string | WaanX server timestamp (nano)  |


---

### Request Example

<Tabs groupId="programming-languages">
<TabItem value="http" label="HTTP">

```http

Host: api.waanx.com
```

</TabItem>
