## Become A Master Trader
Please go [here](https://waanx.com) to apply to become a Master Trader

## Create The API KEY
"Spot - Trade" are mandatory permissions for Copy Trading orders

## Understand The Scope
Copy trading accounts can only trade spot symbols. Please
check [Get Instruments Info](./market/instrument#) for the tradable symbols

## Place The Copy Trading Order
Use V5 [Place Order](./order/create-order) endpoint to place a Copy Trading order

```http
POST /v5/order/create HTTP/1.1
Host: api.waanx.com
X-BAPI-SIGN: XXXXXX
X-BAPI-API-KEY: xxxxxxxxxxxxxxxxxx
X-BAPI-TIMESTAMP: 1698376189371
X-BAPI-RECV-WINDOW: 5000
Content-Type: application/json
Content-Length: 207

{
    "symbol": "BTCUSDT",
    "side": "Buy",
    "orderType": "Limit",
    "category": "spot",
    "qty": "0.1",
    "price": "29000",
    "timeInForce": "GTC"
}
```
