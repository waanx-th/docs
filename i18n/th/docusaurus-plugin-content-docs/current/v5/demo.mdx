## บทนำ
WaanX v5 Open API รองรับบัญชีเทสต์เน็ต แต่โปรดทราบว่า**ไม่ใช่**ทุก API ที่ใช้ได้กับบัญชีเทสต์เน็ต เนื่องจากบริการเทสต์เน็ตนั้น
มีวัตถุประสงค์หลักเพื่อให้ทดลองประสบการณ์การเทรด จึงมีฟังก์ชันไม่ครบถ้วนเมื่อเทียบกับบริการเทรดจริง

## สร้างคีย์ API
1. คุณต้องเข้าสู่ระบบบัญชี[เมนเน็ต](https://www.waanx.com)ของคุณ;
2. สลับไปที่ `Testnet` โปรดทราบว่าเป็นบัญชีแยกอิสระสำหรับเทสต์เน็ตเท่านั้น และมี user ID ของตัวเอง;
3. วางเมาส์บนรูปโปรไฟล์ผู้ใช้ แล้วคลิก "API" เพื่อสร้าง api key และ secret;

## กฎการใช้งาน
* กฎการเทรดพื้นฐานเหมือนกับการเทรดจริง
* คำสั่งซื้อขายที่สร้างในเทสต์เน็ตจะถูกเก็บไว้ **7 วัน**
* ใช้การจำกัดอัตราการเรียกค่าเริ่มต้น ไม่สามารถอัปเกรดได้

## โดเมน
Rest API: `https://api-testnet.waanx.com`<br/>
Websocket: `wss://stream-testnet.waanx.com` (โปรดทราบว่ารองรับเฉพาะสตรีมส่วนตัวเท่านั้น ข้อมูลสาธารณะเหมือนกับที่พบในเมนเน็ตด้วย `wss://stream.waanx.com` และไม่รองรับ WS Trade)

## เคล็ดลับ
* โปรดทราบว่าเทสต์เน็ตเป็นโมดูลที่แยกออกมา เมื่อคุณสร้างคีย์จากเทสต์เน็ต โปรดใช้โดเมนด้านบนในการเชื่อมต่อ

### ขอรับเงินทดลองในเทสต์เน็ต
> การจำกัดอัตราการเรียก API: 1 คำขอต่อนาที

#### คำขอ HTTP
<APIEndpoint method="POST" url="/v5/account/demo-apply-money" />

#### พารามิเตอร์คำขอ {#request-parameters}
| พารามิเตอร์ | จำเป็น | ประเภท | คำอธิบาย|
|:----- |:-------|:-----|------ |
|adjustType|false|integer |`0`(default): เพิ่มเงินทดลองในเทสต์เน็ต; `1`: ลดเงินทดลองในเทสต์เน็ต|
|utaDemoApplyMoney|false|array ||
|> coin |false|string|เหรียญที่ขอรับ รองรับ `BTC`, `ETH`, `USDT`, `USDC`|
|> amountStr |false|string|จำนวนที่ขอรับ โดยจำนวนสูงสุดที่ขอรับได้ในแต่ละคำขอ <ul><li>`BTC`: "15"</li><li>`ETH`: "200"</li><li>`USDT`: "100000"</li><li>`USDC`: "100000"</li></ul>|

#### ตัวอย่างคำขอ
```http
POST /v5/account/demo-apply-money HTTP/1.1
Host: api-testnet.waanx.com
X-BAPI-SIGN: XXXXXXX
X-BAPI-API-KEY: xxxxxxxxxxxxxxxxxx
X-BAPI-TIMESTAMP: 1711420489915
X-BAPI-RECV-WINDOW: 5000
Content-Type: application/json

{
    "adjustType": 0,
    "utaDemoApplyMoney": [
        {
            "coin": "USDT",
            "amountStr": "109"
        },
        {
            "coin": "ETH",
            "amountStr": "1"
        }
    ]
}
```

### สร้างบัญชีเทสต์เน็ต
> การจำกัดอัตราการเรียก API: 5 คำขอต่อวินาที<br/>
> สิทธิ์: AccountTransfer, SubMemberTransfer หรือ SubMemberTransferList

:::info
* ใช้คีย์ของบัญชีหลักหรือบัญชีย่อยบนระบบจริงเพื่อเรียกใช้อินเทอร์เฟซ โดยโดเมนต้องเป็น "api.waanx.com"
* หากมีบัญชีเทสต์เน็ตอยู่แล้ว คำขอ POST นี้จะส่งคืน UID ที่มีอยู่โดยตรง
* หากเรียกใช้ด้วยคีย์ของบัญชีหลัก บัญชีเทสต์เน็ตที่สร้างขึ้นจะอยู่ภายใต้บัญชีหลัก
* หากเรียกใช้ด้วยคีย์ของบัญชีย่อย บัญชีเทสต์เน็ตที่สร้างขึ้นจะอยู่ภายใต้บัญชีย่อย
:::

#### คำขอ HTTP
<APIEndpoint method="POST" url="/v5/user/create-demo-member" />

#### พารามิเตอร์คำขอ
ไม่มี

#### พารามิเตอร์การตอบกลับ {#response-parameters}
| พารามิเตอร์ | ประเภท | คำอธิบาย|
|:----- |:-----|----- |
|subMemberId |string |ID ของบัญชีเทสต์เน็ต |

#### ตัวอย่างคำขอ
```http
POST /v5/user/create-demo-member HTTP/1.1
Host: api.waanx.com
X-BAPI-SIGN: XXXXXXX
X-BAPI-API-KEY: xxxxxxxxxxxxxxxxxx
X-BAPI-TIMESTAMP: 1728460942776
X-BAPI-RECV-WINDOW: 5000
Content-Type: application/json
Content-Length: 2

{}
```
