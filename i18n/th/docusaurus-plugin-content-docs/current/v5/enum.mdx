### orderStatus
_สถานะที่ยังดำเนินอยู่_
* `New`&emsp;สร้างคำสั่งซื้อขายสำเร็จแล้ว
* `PartiallyFilled`
* `Untriggered`&emsp;คำสั่งแบบมีเงื่อนไขถูกสร้างขึ้นแล้ว

_สถานะสิ้นสุด_
* `Rejected`
* `PartiallyFilledCanceled`&emsp;มีเฉพาะสปอตเท่านั้นที่มีสถานะคำสั่งซื้อขายนี้
* `Filled`
* `Cancelled`
* `Triggered`&emsp;สถานะชั่วขณะของคำสั่งแบบมีเงื่อนไขที่เปลี่ยนจาก Untriggered ไปเป็น New
* `Deactivated`&emsp;UTA: คำสั่ง tp/sl ของสปอต คำสั่งแบบมีเงื่อนไข และคำสั่ง OCO ถูกยกเลิกก่อนที่จะถูกทริกเกอร์

### timeInForce
- `GTC`&emsp;มีผลจนกว่าจะยกเลิก
- `IOC`&emsp;จับคู่ทันทีเท่าที่ทำได้แล้วยกเลิกส่วนที่เหลือ
- `FOK`&emsp;ต้องจับคู่ทั้งจำนวนหรือยกเลิกทั้งหมด
- <a href="https://support.waanx.com/en/support/home">PostOnly</a>
- [RPI](https://support.waanx.com/en/support/home)&emsp;คุณสมบัติ:
  - <b>การจับคู่แบบจำกัดเฉพาะ</b>: จับคู่กับผู้ใช้ที่ไม่ใช้อัลกอริทึมเท่านั้น ไม่จับคู่กับคำสั่งซื้อขายจาก Open API
  - <b>กลไก Post-Only</b>: ทำหน้าที่เป็นคำสั่งฝั่ง maker เพื่อเพิ่มสภาพคล่อง
  - <b>ลำดับความสำคัญต่ำกว่า</b>: จับคู่หลังคำสั่งซื้อขายที่ไม่ใช่ RPI ที่ระดับราคาเดียวกัน
  - <b>การเข้าถึงแบบจำกัด</b>: ในช่วงแรกเปิดให้เฉพาะ market maker ที่ได้รับคัดเลือกในหลายคู่เทรด
  - <b>การอัปเดตสมุดคำสั่งซื้อขาย</b>: ไม่รวมอยู่ใน API แต่จะแสดงบน GUI
