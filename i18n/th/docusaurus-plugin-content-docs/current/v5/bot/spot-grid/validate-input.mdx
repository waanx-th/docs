ตรวจสอบพารามิเตอร์ของบอทกริดสปอตก่อนการสร้าง โดยจะส่งคืนช่วงค่าที่ยอมรับได้ของแต่ละพารามิเตอร์ และรหัสตรวจสอบที่ระบุข้อผิดพลาดในการตรวจสอบ

:::info
- **เวลาที่ควรเรียกใช้:**<br/>
ควรเรียกเอนด์พอยต์นี้ก่อน [สร้างบอทกริดสปอต](./create) ทุกครั้ง เพื่อให้แน่ใจว่าพารามิเตอร์อยู่ในขอบเขตที่ถูกต้อง

- **`check_code`:**<br/>
`SPOT_CHECK_CODE_SUCCESS_UNSPECIFIED` (ค่า `0`) หมายความว่าพารามิเตอร์ทั้งหมดถูกต้อง ค่าอื่นใดจะระบุพารามิเตอร์ที่อยู่นอกช่วงที่กำหนด

- **การยืนยันตัวตน:**<br/>
เอนด์พอยต์นี้**ไม่**ต้องการการยืนยันตัวตน (โหมดผู้เยี่ยมชม)

- **การจำกัดอัตราการเรียก:**<br/>
100 คำขอต่อวินาทีต่อ IP
:::

### คำขอ HTTP
<APIEndpoint method="POST" url="/v5/grid/validate-input" />

### พารามิเตอร์คำขอ {#request-parameters}
| พารามิเตอร์ | จำเป็น | ประเภท | คำอธิบาย |
|:----------|:---------|:-----|---------|
|symbol |**true** |string |สัญลักษณ์คู่เทรด ตัวพิมพ์ใหญ่เท่านั้น (เช่น `BTCUSDT`)|
|cell_number |**true** |integer |จำนวนช่วงกริด ต่ำสุด 2|
|min_price |**true** |string |ขอบล่างของช่วงราคากริด (สตริงทศนิยม)|
|max_price |**true** |string |ขอบบนของช่วงราคากริด ต้องมากกว่า `min_price` (สตริงทศนิยม)|
|invest_mode |false |integer |โหมดการลงทุน: `0` โทเคนอ้างอิงเท่านั้น (default), `1` โทเคนฐานเท่านั้น, `2` โทเคนฐาน + โทเคนอ้างอิง|
|base_investment |false |string |เงินลงทุนในหน่วยโทเคนฐาน (สตริงทศนิยม) **จำเป็น** เมื่อ `invest_mode` เป็น `1` หรือ `2`|
|quote_investment |false |string |เงินลงทุนในหน่วยโทเคนอ้างอิง (สตริงทศนิยม) **จำเป็น** เมื่อ `invest_mode` เป็น `0` หรือ `2`|
|stop_loss |false |string |หยุดขาดทุนในรูปราคาสัมบูรณ์ (สตริงทศนิยม)|
|take_profit |false |string |ทำกำไรในรูปราคาสัมบูรณ์ (สตริงทศนิยม)|
|entry_price |false |string |ราคาเข้าตำแหน่งในรูปราคาสัมบูรณ์ (สตริงทศนิยม)|
|ts_percent |false |string |อัตราการดึงกลับของ trailing stop ช่วง `[0, 0.99]` (เช่น `"0.05"` หมายถึง 5%)|
|enable_trailing |false |boolean |จะเปิดใช้การเลื่อนกริดตามราคาหรือไม่ ต้องมี `cell_number >= 5`|
|limit_up_price |false |string |ราคาขีดจำกัดสูงสุดสำหรับการเลื่อนกริดตามราคา (สตริงทศนิยม)|

### พารามิเตอร์การตอบกลับ {#response-parameters}
| พารามิเตอร์ | ประเภท | คำอธิบาย |
|:----------|:-----|---------|
|status_code |integer |`0` หรือ `200` = สำเร็จ|
|debug_msg |string |ข้อความดีบัก (เทสต์เน็ตเท่านั้น)|
|check_code |string |รหัสผลการตรวจสอบ `SPOT_CHECK_CODE_SUCCESS_UNSPECIFIED` = ปกติ ดูตารางรหัสตรวจสอบด้านล่าง|
|investment |object |ช่วงที่ยอมรับได้ของยอดลงทุนรวม (`from` / `to`, สตริงทศนิยม)|
|profit |object |ช่วงที่ยอมรับได้ของอัตรากำไรต่อกริดในรูปอัตราส่วนทศนิยม (`from` / `to`)|
|cell_number |object |ช่วงที่ยอมรับได้ของจำนวนกริด (`from` / `to`)|
|min_price |object |ช่วงที่ยอมรับได้ของขอบราคาล่าง (`from` / `to`)|
|max_price |object |ช่วงที่ยอมรับได้ของขอบราคาบน (`from` / `to`)|
|stop_loss |object |ช่วงที่ยอมรับได้ของราคาหยุดขาดทุน (`from` / `to`)|
|take_profit |object |ช่วงที่ยอมรับได้ของราคาทำกำไร (`from` / `to`)|
|entry_price |object |ช่วงที่ยอมรับได้ของราคาเข้าตำแหน่ง (`from` / `to`)|
|base_investment |object |ช่วงที่ยอมรับได้ของเงินลงทุนในโทเคนฐาน (`from` / `to`)|
|cell_distance |string |ระยะห่างของช่วงกริดในหน่วยราคาของโทเคนอ้างอิง (สตริงทศนิยม)|
|ts_percent |object |ช่วงที่ยอมรับได้ของอัตรา trailing stop (`from` / `to`)|
|limit_up_price |object |ช่วงที่ยอมรับได้ของราคาขีดจำกัดสูงสุดสำหรับการเลื่อนกริด (`from` / `to`)|

#### ค่าของ Check Code

| check_code | คำอธิบาย |
|:-----------|:-----------|
|`SPOT_CHECK_CODE_SUCCESS_UNSPECIFIED` |ปกติ — ไม่มีข้อผิดพลาด|
|`SPOT_CHECK_CODE_LOW_PRICE_TOO_LOW` |`min_price` ต่ำเกินไป|
|`SPOT_CHECK_CODE_LOW_PRICE_TOO_HIGH` |`min_price` สูงเกินไป|
|`SPOT_CHECK_CODE_HIGH_PRICE_TOO_LOW` |`max_price` ต่ำเกินไป|
|`SPOT_CHECK_CODE_HIGH_PRICE_TOO_HIGH` |`max_price` สูงเกินไป|
|`SPOT_CHECK_CODE_GRID_NO_TOO_LOW` |`cell_number` น้อยเกินไป|
|`SPOT_CHECK_CODE_GRID_NO_TOO_HIGH` |`cell_number` มากเกินไป|
|`SPOT_CHECK_CODE_INVESTMENT_TOO_LOW` |เงินลงทุนต่ำเกินไป|
|`SPOT_CHECK_CODE_INVESTMENT_TOO_HIGH` |เงินลงทุนสูงเกินไป|
|`SPOT_CHECK_CODE_TP_TOO_LOW` |ราคาทำกำไรต่ำเกินไป|
|`SPOT_CHECK_CODE_TP_TOO_HIGH` |ราคาทำกำไรสูงเกินไป|
|`SPOT_CHECK_CODE_SL_TOO_LOW` |ราคาหยุดขาดทุนต่ำเกินไป|
|`SPOT_CHECK_CODE_SL_TOO_HIGH` |ราคาหยุดขาดทุนสูงเกินไป|
|`SPOT_CHECK_CODE_EP_TOO_LOW` |ราคาเข้าตำแหน่งต่ำเกินไป|
|`SPOT_CHECK_CODE_EP_TOO_HIGH` |ราคาเข้าตำแหน่งสูงเกินไป|
|`SPOT_CHECK_CODE_TS_PERCENT_TOO_LOW` |เปอร์เซ็นต์ trailing stop ต่ำเกินไป|
|`SPOT_CHECK_CODE_TS_PERCENT_TOO_HIGH` |เปอร์เซ็นต์ trailing stop สูงเกินไป|
|`SPOT_CHECK_CODE_TP_TOO_LOW_THAN_MARKET` |ราคาทำกำไรต่ำเกินไปเมื่อเทียบกับราคาตลาด|
|`SPOT_CHECK_CODE_SL_TOO_HIGH_THAN_MARKET` |ราคาหยุดขาดทุนสูงเกินไปเมื่อเทียบกับราคาตลาด|
|`SPOT_CHECK_CODE_LIMIT_UP_PRICE_TOO_LOW` |`limit_up_price` ต่ำเกินไป|
|`SPOT_CHECK_CODE_LIMIT_UP_PRICE_TOO_HIGH` |`limit_up_price` สูงเกินไป|
|`SPOT_CHECK_CODE_CAN_NOT_ENABLE_TRAILING_UP` |`cell_number < 5` ไม่อนุญาตให้เลื่อนกริด|
|`SPOT_CHECK_CODE_ENTRY_PRICE_FORBIDDEN_TRAILING_UP` |ราคาเข้าตำแหน่งอยู่นอกช่วงกริด ไม่อนุญาตให้เลื่อนกริด|
|`SPOT_CHECK_CODE_LAST_PRICE_FORBIDDEN_TRAILING_UP` |ราคาตลาดอยู่นอกช่วงกริด ไม่อนุญาตให้เลื่อนกริด|
|`SPOT_CHECK_CODE_INVESTMENT_FORBIDDEN_TRAILING_UP` |เงินลงทุนน้อยเกินไปสำหรับการเลื่อนกริด|
