สร้างบอทเทรดกริดสปอตใหม่ด้วยคู่เทรด ช่วงราคา จำนวนกริด และยอดเงินลงทุนที่ระบุ

:::info
- **ข้อกำหนดเบื้องต้น:**<br/>
เรียก [ตรวจสอบพารามิเตอร์กริดสปอต](./validate-input) ก่อนเรียกเอนด์พอยต์นี้ เพื่อให้แน่ใจว่าพารามิเตอร์อยู่ในช่วงที่ถูกต้อง<br/>
ผู้ใช้ต้องผ่านการยืนยันตัวตนและผ่านการตรวจสอบ KYC/การกำกับดูแล

- **โหมดการลงทุน (`invest_mode`):**<br/>
`0`: โทเคนอ้างอิงเท่านั้น (default) — ลงทุนด้วยโทเคนอ้างอิง (เช่น USDT)<br/>
`1`: โทเคนฐานเท่านั้น — ลงทุนด้วยโทเคนฐาน (เช่น BTC)<br/>
`2`: โทเคนฐาน + โทเคนอ้างอิง — แบ่งเงินลงทุนระหว่างโทเคนทั้งสอง

- **การเลื่อนกริดตามราคา (`enable_trailing`):**<br/>
เมื่อเปิดใช้งาน กริดจะเลื่อนโดยอัตโนมัติเมื่อราคาเปลี่ยนแปลง ต้องมี `cell_number >= 5`

- **`grid_id` ในการตอบกลับ:**<br/>
จะถูกส่งคืนเมื่อสำเร็จ ใช้ ID นี้สำหรับการดำเนินการ [ดูรายละเอียด](./get-detail) และ [ปิดบอท](./close) ในภายหลัง

- **การจำกัดอัตราการเรียก:**<br/>
3 คำขอต่อวินาทีต่อ UID

- **อยู่ภายใต้ข้อกำหนดด้านการกำกับดูแลและการยืนยันตัวตน KYC**<br/>
หากผู้ใช้ถูกระงับการใช้งาน (status_code=421) ฟิลด์ `ban_reason_text` จะให้คำอธิบายในภาษาท้องถิ่น
:::

### คำขอ HTTP
<APIEndpoint method="POST" url="/v5/grid/create-grid" />

### พารามิเตอร์คำขอ {#request-parameters}
| พารามิเตอร์ | จำเป็น | ประเภท | คำอธิบาย |
|:----------|:---------|:-----|---------|
|symbol |**true** |string |สัญลักษณ์คู่เทรด ตัวพิมพ์ใหญ่เท่านั้น (เช่น `BTCUSDT`)|
|max_price |**true** |string |ขอบบนของช่วงราคากริด (สตริงทศนิยม)|
|min_price |**true** |string |ขอบล่างของช่วงราคากริด (สตริงทศนิยม)|
|cell_number |**true** |integer |จำนวนช่วงกริด ต่ำสุด 2|
|invest_mode |false |integer |โหมดการลงทุน `0`: โทเคนอ้างอิงเท่านั้น (default), `1`: โทเคนฐานเท่านั้น, `2`: โทเคนฐาน + โทเคนอ้างอิง|
|base_investment |false |string |เงินลงทุนในหน่วยโทเคนฐาน (สตริงทศนิยม) **จำเป็น** เมื่อ `invest_mode` เป็น `1` หรือ `2`|
|quote_investment |false |string |เงินลงทุนในหน่วยโทเคนอ้างอิง (สตริงทศนิยม) **จำเป็น** เมื่อ `invest_mode` เป็น `0` หรือ `2`|
|entry_price |false |string |ราคาทริกเกอร์เข้าตำแหน่ง (สตริงทศนิยม) บอทจะเริ่มทำงานเมื่อราคาตลาดถึงระดับนี้|
|stop_loss_price |false |string |ราคาทริกเกอร์หยุดขาดทุน (สตริงทศนิยม)|
|take_profit_price |false |string |ราคาทริกเกอร์ทำกำไร (สตริงทศนิยม)|
|ts_percent |false |string |อัตราการดึงกลับของ trailing stop ช่วง `[0, 0.99]` (เช่น `"0.05"` หมายถึง 5%)|
|enable_trailing |false |boolean |เปิดใช้การเลื่อนกริดตามราคา (เลื่อนอัตโนมัติ) ต้องมี `cell_number >= 5` ค่าเริ่มต้น: `false`|
|limit_up_price |false |string |ราคาขีดจำกัดสูงสุดสำหรับการเลื่อนกริดตามราคา (สตริงทศนิยม) ใช้เมื่อ "enable_trailing"=`true`|

### พารามิเตอร์การตอบกลับ {#response-parameters}
| พารามิเตอร์ | ประเภท | คำอธิบาย |
|:----------|:-----|---------|
|status_code |integer |`200` = สำเร็จ, `421` = ผู้ใช้ถูกระงับการใช้งาน|
|grid_id |integer |ID ของบอทกริดที่สร้างขึ้น ใช้สำหรับการค้นหาข้อมูลและการปิดบอทในภายหลัง|
|ban_reason_text |string |สาเหตุการระงับการใช้งานในภาษาของผู้ใช้ ส่งคืนเฉพาะเมื่อ `status_code=421`|
|debug_msg |string |ข้อความดีบัก (เทสต์เน็ตเท่านั้น)|
