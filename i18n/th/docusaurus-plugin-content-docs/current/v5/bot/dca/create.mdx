สร้างบอท DCA (Dollar-Cost Averaging) ใหม่ที่ลงทุนโดยอัตโนมัติตามช่วงเวลาสม่ำเสมอในคู่เทรดที่ระบุ

:::info
- **หลักการทำงาน:**<br/>
บอทจะซื้อคู่เทรดที่ตั้งค่าไว้แต่ละคู่ด้วยจำนวนคงที่ทุกช่วงเวลา `frequency_in_second` โดยไม่คำนึงถึงราคาตลาด

- **คู่เทรดที่รองรับ:**<br/>
สูงสุด **5** คู่ต่อบอทหนึ่งตัว

- **ความถี่ต่ำสุด:**<br/>
10 วินาที ค่าที่ใช้ทั่วไป: `600` (10 นาที), `3600` (1 ชั่วโมง), `86400` (1 วัน)

- **`max_invest_amount`:**<br/>
ขีดจำกัดยอดลงทุนสะสมทั้งหมด ซึ่งไม่จำเป็นต้องระบุ บอทจะปิดตัวเองโดยอัตโนมัติเมื่อยอดใช้จ่ายสะสมถึงจำนวนนี้

- **`bot_id` ในการตอบกลับ:**<br/>
จะถูกส่งคืนเมื่อสำเร็จ ใช้ ID นี้สำหรับการดำเนินการ [ปิดบอท](./close) ในภายหลัง

- **การจำกัดอัตราการเรียก:**<br/>
3 คำขอต่อวินาทีต่อ UID

- **อยู่ภายใต้ข้อกำหนดด้านการกำกับดูแลและการยืนยันตัวตน KYC**<br/>
หากผู้ใช้ถูกระงับการใช้งาน (status_code=421) ฟิลด์ `ban_reason_text` จะให้คำอธิบายในภาษาท้องถิ่น
:::

### คำขอ HTTP
<APIEndpoint method="POST" url="/v5/dca/create-bot" />

### พารามิเตอร์คำขอ {#request-parameters}
| พารามิเตอร์ | จำเป็น | ประเภท | คำอธิบาย |
|:----------|:---------|:-----|---------|
|parameters |**true** |object |ออบเจ็กต์การตั้งค่าบอท DCA (ดูด้านล่าง)|
|> frequency_in_second |**true** |integer |ความถี่การลงทุนเป็นวินาที ต่ำสุด `10` ค่าที่ใช้ทั่วไป: `600` (10 นาที), `3600` (1 ชั่วโมง), `86400` (1 วัน)|
|> quote_coin |**true** |string |โทเคนอ้างอิงที่ใช้ในการซื้อ (เช่น `USDT`, `USDC`)|
|> pairs |**true** |array |คู่เทรดที่จะลงทุน สูงสุด 5 คู่|
|>> base |**true** |string |เหรียญที่จะลงทุน (เช่น `BTC`)|
|>> amount |**true** |string |จำนวนเงินลงทุนต่อรอบในหน่วยเหรียญอ้างอิง (สตริงทศนิยม เช่น `"10"` หมายถึง 10 USDT)|
|> max_invest_amount |false |string |ไม่จำเป็น ยอดลงทุนรวมสูงสุดในหน่วยเหรียญอ้างอิง (สตริงทศนิยม) บอทจะปิดตัวเองโดยอัตโนมัติเมื่อถึงยอดนี้|

### พารามิเตอร์การตอบกลับ {#response-parameters}
| พารามิเตอร์ | ประเภท | คำอธิบาย |
|:----------|:-----|---------|
|status_code |integer |`200` = สำเร็จ, `421` = ผู้ใช้ถูกระงับการใช้งาน|
|bot_id |integer |ID ของบอท DCA ที่สร้างขึ้น ใช้สำหรับการดำเนินการปิดบอทในภายหลัง|
|debug_msg |string |สาเหตุที่การสร้างล้มเหลว (เทสต์เน็ต: ข้อมูลดีบัก)|
|ban_reason_text |string |สาเหตุการระงับการใช้งานในภาษาของผู้ใช้ ส่งคืนเฉพาะเมื่อ `status_code=421`|

### ตัวอย่างคำขอ

```http
POST /v5/dca/create-bot HTTP/1.1
Host: api.waanx.com
X-BAPI-SIGN: XXXXX
X-BAPI-API-KEY: xxxxxxxxxxxxxxxxxx
X-BAPI-TIMESTAMP: 1672211928338
X-BAPI-RECV-WINDOW: 5000
Content-Type: application/json

{
    "parameters": {
        "frequency_in_second": "600",
        "quote_coin": "USDT",
        "max_invest_amount": "2000",
        "pairs": [
            {
                "base": "BTC",
                "amount": "66"
            },
            {
                "base": "ETH",
                "amount": "88"
            }
        ]
    }
}
```

