รหัสข้อผิดพลาดระดับ HTTP ที่ส่งคืนโดย Bot API

## บอท DCA

ใช้กับ: [สร้างบอท](./dca/create), [ปิดบอท](./dca/close)

| error_code | error_msg | เอนด์พอยต์ที่เกี่ยวข้อง |
|:----------:|:----------|:----------------------|
| 400 | พารามิเตอร์ไม่ถูกต้อง (เช่น สัญลักษณ์คู่เทรดซ้ำกัน, ความถี่ไม่ถูกต้อง) | สร้างบอท |
| 421 | ผู้ใช้ถูกระงับการใช้งาน | สร้างบอท |
| 503 | ไม่สามารถปิดบอทได้ในขณะนี้ (อยู่ระหว่างรอบการลงทุน) | ปิดบอท |

---

## บอทกริดสปอต

ใช้กับ: [สร้างบอท](./spot-grid/create), [ปิดบอท](./spot-grid/close), [ดูรายละเอียด](./spot-grid/get-detail), [ตรวจสอบพารามิเตอร์](./spot-grid/validate-input)

| error_code | error_msg | เอนด์พอยต์ที่เกี่ยวข้อง |
|:----------:|:----------|:----------------------|
| 400 | พารามิเตอร์คำขอไม่ถูกต้อง | สร้างบอท, ตรวจสอบพารามิเตอร์ |
| 401 | ยอดคงเหลือไม่เพียงพอ | สร้างบอท |
| 404 | ไม่พบบอทกริด | ดูรายละเอียด |
| 405 | ไม่สามารถยกเลิกกริดได้ (อยู่ในสถานะ CANCELLING หรือ COMPLETED แล้ว) | ปิดบอท |
| 421 | ผู้ใช้ถูกระงับการใช้งาน | สร้างบอท |
