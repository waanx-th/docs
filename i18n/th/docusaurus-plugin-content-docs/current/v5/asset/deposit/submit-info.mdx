ส่งข้อมูลด้านการกำกับดูแลของผู้ริเริ่มธุรกรรมเมื่อรายการฝากทำให้เกิดการตรวจสอบ Travel Rule หลังการส่งข้อมูล ผู้ให้บริการจะดำเนินการตรวจสอบและคืนสถานะผลลัพธ์กลับมา

:::info
เรียกเอนด์พอยต์นี้เมื่อรายการฝากเข้าเงื่อนไขนโยบายการกำกับดูแล Travel Rule และค่า `travel_rule_status` ปัจจุบันเป็น `1` (รอการส่งข้อมูลคู่สัญญา)
:::

### คำขอ HTTP
<APIEndpoint method="POST" url="/v5/asset/travel-rule/deposit/submit" />

### พารามิเตอร์คำขอ {#request-parameters}
| พารามิเตอร์ | จำเป็น | ประเภท | คำอธิบาย|
|:----- |:-------|:-----|------ |
|depositId |**true** |integer |ID ของรายการฝากที่ได้จาก API เรียกดูรายการฝาก|
|subAccountId |false |integer |กรณีโบรกเกอร์: UID ของบัญชีย่อยเป้าหมาย ส่งค่า `0` หรือไม่ระบุเพื่อใช้บัญชีปัจจุบัน |
|questionnaire |**true** |string |ข้อมูลแบบสอบถาม Travel Rule ในรูปสตริง JSON ขนาดสูงสุด 16384 ไบต์ โครงสร้างแตกต่างกันตามเขตการกำกับดูแล ดู [แบบสอบถาม](../withdraw/questionnaire) |

### พารามิเตอร์การตอบกลับ {#response-parameters}
| พารามิเตอร์ | ประเภท | คำอธิบาย|
|:----- |:-----|----- |
|travelRuleStatus |integer|สถานะการตรวจสอบ Travel Rule <ul><li>`0`: Approved — ตรวจสอบผ่าน ดำเนินขั้นตอนถัดไปได้</li><li>`1`: CollectInfo — ต้องระบุข้อมูลคู่สัญญา ให้ส่งแบบสอบถามอีกครั้ง</li><li>`2`: Pending — อยู่ระหว่างการตรวจสอบ ให้เรียกเอนด์พอยต์สอบถามรายการฝากซ้ำเป็นรอบ</li><li>`3`: Rejected — ถูกปฏิเสธหรือไม่ผ่าน (รวมถึงกรณีที่ถูกยกเลิก)</li></ul> |
