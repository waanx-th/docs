:::info
1. การแลกเปลี่ยนทำงานแบบอะซิงโครนัส โปรดตรวจสอบสถานะสุดท้ายโดยเรียก API สอบถามผลลัพธ์
2. โปรดยืนยันราคาเสนอก่อนที่ราคาเสนอจะหมดอายุ
:::

### คำขอ HTTP
<APIEndpoint method="POST" url="/v5/asset/exchange/convert-execute" />

### พารามิเตอร์คำขอ {#request-parameters}
| พารามิเตอร์ | จำเป็น | ประเภท | หมายเหตุ|
|:----- |:-------|:-----|------ |
|quoteTxId |**true** |string |ID ธุรกรรมของราคาเสนอที่ได้จาก [ขอราคาเสนอ](apply-quote#response-parameters)|

### พารามิเตอร์การตอบกลับ {#response-parameters}
| พารามิเตอร์ | ประเภท | หมายเหตุ|
|:----- |:-----|----- |
|quoteTxId |string|ID ธุรกรรมของราคาเสนอ|
|exchangeStatus |string|สถานะการแลกเปลี่ยน <ul><li>init</li><li>processing</li><li>success</li><li>failure</li></ul>|
