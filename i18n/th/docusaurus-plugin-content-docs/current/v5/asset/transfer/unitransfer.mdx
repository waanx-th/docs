โอนระหว่างบัญชีย่อยกับบัญชีย่อย หรือระหว่างบัญชีหลักกับบัญชีย่อย

:::tip
* ใช้คีย์ API ของบัญชีหลักหรือบัญชีย่อยในการเรียก <ul><li>หากจะใช้คีย์ API ของบัญชีย่อย คีย์นั้นต้องมีสิทธิ์ "SubMemberTransferList"</li><li>เมื่อใช้คีย์ API ของบัญชีย่อย จะโอนไปยังบัญชีหลักได้เท่านั้น</li></ul>
* หากพบ errorCode: `131228` และ msg: `your balance is not enough` โปรดไปที่ [ดึงยอดคงเหลือของเหรียญเดียว](../balance/account-coin-balance#) เพื่อตรวจสอบจำนวนที่โอนได้อย่างปลอดภัย
* คุณไม่สามารถโอนระหว่าง UID เดียวกันได้
:::

### คำขอ HTTP
<APIEndpoint method="POST" url="/v5/asset/transfer/universal-transfer" />

### พารามิเตอร์คำขอ {#request-parameters}
| พารามิเตอร์ | จำเป็น | ประเภท | คำอธิบาย|
|:----- |:-------|:-----|------ |
|transferId |**true** |string |[UUID](https://www.uuidgenerator.net/dev-corner) โปรดสร้าง UUID ด้วยตนเอง |
|coin |**true** |string |เหรียญ ตัวพิมพ์ใหญ่เท่านั้น |
|amount |**true** |string |จำนวน |
|fromMemberId |**true** |integer |UID ต้นทาง |
|toMemberId |**true** |integer |UID ปลายทาง |
|[fromAccountType](../../enum#accounttype) |**true** |string |ประเภทบัญชีต้นทาง |
|[toAccountType](../../enum#accounttype) |**true** |string |ประเภทบัญชีปลายทาง |

### พารามิเตอร์การตอบกลับ {#response-parameters}
| พารามิเตอร์ | ประเภท | คำอธิบาย|
|:----- |:-----|----- |
|transferId |string|UUID |
|status |string|สถานะการโอน <ul><li>`STATUS_UNKNOWN`</li><li>`SUCCESS`</li><li>`PENDING`</li><li>`FAILED`</li></ul> |
