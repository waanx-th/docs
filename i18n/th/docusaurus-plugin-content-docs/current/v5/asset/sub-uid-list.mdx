สอบถาม UID ของบัญชีย่อยที่อยู่ภายใต้ UID หลัก จะคืนค่าบัญชีย่อยได้สูงสุด 2000 บัญชี หากต้องการมากกว่านี้ โปรดเรียก[เอนด์พอยต์นี้](../user/page-subuid)

:::info
สอบถามได้ด้วยคีย์ API ของ UID บัญชีหลัก**เท่านั้น**
:::

### คำขอ HTTP
<APIEndpoint method="GET" url="/v5/asset/transfer/query-sub-member-list" />

### พารามิเตอร์คำขอ {#request-parameters}
ไม่มี

### พารามิเตอร์การตอบกลับ {#response-parameters}
| พารามิเตอร์ | ประเภท | คำอธิบาย|
|:----- |:-----|----- |
|subMemberIds |array&lt;string&gt; |UID ของบัญชีย่อยทั้งหมดที่อยู่ภายใต้ UID หลัก |
|transferableSubMemberIds |array&lt;string&gt; |UID ของบัญชีย่อยทั้งหมดที่เปิดใช้งานการโอนแบบ Universal |


---
