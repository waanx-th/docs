:::info
* สิทธิ์ของคีย์ API: `Convert`
* การจำกัดอัตราการเรียก API: `10 req /s`
* คุณสามารถสอบถามบันทึกการแลกเปลี่ยนยอดคงเหลือจำนวนน้อยทั้งหมดที่ทำผ่าน API หรือเว็บ/แอป จากทั้งกระเป๋าเงินแบบรวมและกระเป๋าเงินสำหรับเติมทุน
:::

### คำขอ HTTP
<APIEndpoint method="GET" url="/v5/asset/covert/small-balance-history" />

### พารามิเตอร์คำขอ {#request-parameters}
| พารามิเตอร์ | จำเป็น | ประเภท | หมายเหตุ|
|:----- |:-------|:-----|------ |
|accountType|false |string |`eb_convert_uta`, `eb_convert_funding`|
|quoteId |false |string |ID ราคาเสนอ มีลำดับความสำคัญสูงสุดในการสอบถาม|
|startTime |false |string |ประทับเวลาเริ่มต้น (มิลลิวินาที)|
|endTime |false |string |ประทับเวลาสิ้นสุด (มิลลิวินาที)|
|cursor |false |string |หมายเลขหน้า|
|size |false |string |ขนาดหน้า ค่าเริ่มต้นคือ 50 สูงสุดคือ 100|

### พารามิเตอร์การตอบกลับ {#response-parameters}
| พารามิเตอร์ | ประเภท | หมายเหตุ|
|:----- |:-----|----- |
|cursor |string|หมายเลขหน้าปัจจุบัน|
|size |string|ขนาดหน้าปัจจุบัน|
|lastPage |string|หมายเลขหน้าสุดท้าย|
|totalCount |string|จำนวนบันทึกทั้งหมด|
|records |array&lt;object&gt;||
|> accountType |string|`eb_convert_uta`: กระเป๋าเงินแบบรวม, `eb_convert_funding`: กระเป๋าเงินสำหรับเติมทุน|
|> exchangeTxId |string |ID ธุรกรรมการแลกเปลี่ยน|
|> toCoin |string |สกุลเงินเป้าหมาย |
|> toAmount |string|จำนวนรวมที่ได้รับจริง|
|> subRecords |array&lt;object&gt;|รายละเอียด|
|>> fromCoin |string|สกุลเงินต้นทาง|
|>> fromAmount |string|จำนวนของสกุลเงินต้นทาง|
|>> toCoin |string|สกุลเงินเป้าหมาย|
|>> toAmount |string|จำนวนที่ได้รับจริง|
|>> feeCoin |string|สกุลเงินของค่าธรรมเนียมการแลกเปลี่ยน|
|>> feeAmount |string|ค่าธรรมเนียมการแลกเปลี่ยน|
|>> status |string|`init`, `processing`, `success`, `failure`, `partial_fulfillment`|
|>> taxFeeInfo |object||
|>>> totalAmount |string|จำนวนค่าธรรมเนียมภาษี|
|>>> feeCoin |string|สกุลเงินของค่าธรรมเนียมภาษี|
|>>> taxFeeItems |array|รายการค่าธรรมเนียมภาษี|
|> status |string|`init`, `processing`, `success`, `failure`, `partial_fulfillment`|
|> createdAt |string|ประทับเวลาที่สร้างราคาเสนอ|
|> exchangeSource |string|แหล่งที่มาของการแลกเปลี่ยน `small_asset_uta`, `small_asset_funding`|
|> feeCoin |string|สกุลเงินของค่าธรรมเนียมการแลกเปลี่ยน|
|> totalFeeAmount |string|จำนวนค่าธรรมเนียมการแลกเปลี่ยนรวม|
|> totalTaxFeeInfo |object||
|>> totalAmount |string|จำนวนค่าธรรมเนียมภาษีรวม|
|>> feeCoin |string|สกุลเงินของค่าธรรมเนียมภาษี|
|>> taxFeeItems |array|รายการค่าธรรมเนียมภาษี|
