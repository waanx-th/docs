- **Webhook_url**: กำหนดไว้ใน API [trade-execute](confirm-quote)

- **เมธอด HTTP**: `POST`

### เนื้อหาคำขอ

เนื้อหาคำขออยู่ในรูปแบบ **JSON** โดยมีฟิลด์ดังต่อไปนี้:

| ชื่อฟิลด์ | ประเภท | คำอธิบาย |
|-------------|--------|-----------------------------------------------------------------------------------------------|
| `tradeNo`   | string | หมายเลขคำสั่งเทรด |
| `status`    | string | สถานะการเทรด: `processing`, `success` หรือ `failed` |
| `quoteTxId` | string | รหัสธุรกรรมของใบเสนอราคา ระบบสร้างขึ้นเอง ใช้สำหรับยืนยันใบเสนอราคา |
| `exchangeRate` | string | อัตราแลกเปลี่ยน |
| `fromCoin`  | string | เหรียญต้นทางที่ใช้แปลง (เหรียญที่ต้องการขาย) |
| `fromCoinType` | string | ประเภทเหรียญของ `fromCoin` เป็น `fiat` หรือ `crypto` |
| `toCoin`    | string | เหรียญปลายทางที่แปลงเป็น (เหรียญที่ต้องการซื้อ) |
| `toCoinType` | string | ประเภทเหรียญของ `toCoin` เป็น `fiat` หรือ `crypto` |
| `fromAmount` | string | จำนวนเหรียญต้นทาง (จำนวนที่ต้องการขาย) |
| `toAmount`  | string | จำนวนเหรียญปลายทาง (จำนวนที่จะซื้อได้ตามอัตราแลกเปลี่ยน) |
| `createdAt` | string | เวลาที่สร้างรายการเทรด |
```
