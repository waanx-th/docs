เอนด์พอยต์นี้ใช้สำหรับสอบถามรายการ VASP ที่ใช้ได้ API นี้จะแยกแยะว่าผู้ใช้อยู่ในเขตการกำกับดูแลใด และคืนรายการเอ็กซ์เชนจ์ที่สอดคล้องกันโดยอ้างอิงจาก UID ของผู้ใช้

### คำขอ HTTP
<APIEndpoint method="GET" url="/v5/asset/withdraw/vasp/list" />

### พารามิเตอร์คำขอ {#request-parameters}
ไม่มี

### พารามิเตอร์การตอบกลับ {#response-parameters}
| พารามิเตอร์ | ประเภท | คำอธิบาย|
|:----- |:-----|----- |
|vasp |array|ข้อมูลนิติบุคคลของเอ็กซ์เชนจ์ |
|> vaspEntityId |string |รหัสแพลตฟอร์มผู้รับ เมื่อโอนไปยังเอ็กซ์เชนจ์ที่ไม่อยู่ในรายการ โปรดใช้ vaspEntityId='others'|
|> vaspName |string |ชื่อแพลตฟอร์มผู้รับ|
