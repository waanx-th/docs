ฟิลด์ `questionnaire` เป็นสตริง JSON ที่ใช้ส่งข้อมูลการปฏิบัติตาม Travel Rule ทั้งในเอนด์พอยต์ [ส่งข้อมูลผู้ริเริ่มการฝาก](../deposit/submit-info#) และ [ถอน](/v5/asset/withdraw) โดยใช้แทนการรวม `beneficiary` + `transactionPurpose` แบบเดิมสำหรับการเชื่อมต่อใหม่

:::info
- ความยาวสูงสุด: **16384 bytes**
- เมื่อมีทั้งฟิลด์ `questionnaire` และฟิลด์แบบเดิม `beneficiary`/`transactionPurpose` **`questionnaire` จะมีลำดับความสำคัญสูงกว่า**
- ชื่อฟิลด์ใช้รูปแบบ **lowerCamelCase** (เช่น `walletType`, `poiIssuingCountry`)
- รหัสประเทศเป็นไปตาม **ISO 3166-1 alpha-3** (เช่น `JPN`, `TUR`, `KAZ`, `IND`)
- วันที่เป็นไปตามรูปแบบย่อของ **ISO 8601** `YYYY-MM-DD`
:::

### ฟิลด์ที่ใช้ร่วมกัน

ฟิลด์ต่อไปนี้ใช้กับทุกเขตการกำกับดูแล

| ฟิลด์ | ประเภท | จำเป็น | คำอธิบาย |
|:----- |:-----|:---------|:---------|
|walletType |integer |**true** |ประเภทกระเป๋าเงิน `0`: กระเป๋าเงินแบบ custodial/VASP `1`: กระเป๋าเงินแบบ non-custodial (ส่วนบุคคล) |
|legalType |string |**true** |ประเภทของผู้ทำรายการ `individual`: บุคคลธรรมดา `company`: นิติบุคคล / สถาบัน |
|vaspCode |string(64) |Conditional |รหัส VASP ของคู่สัญญา **จำเป็น** เมื่อ `walletType=0` ใช้ `others` หากไม่มีรายการที่ตรงกัน ดึงรหัสที่ใช้ได้ผ่าน API VASP List |
|isSelfWallet |bool |false |ระบุว่ากระเป๋าเงินเป็นของผู้ใช้เองหรือไม่ ใช้กับกระเป๋าเงินแบบ non-custodial เท่านั้น |
|firstName |string(128) |Conditional |ชื่อ **จำเป็น** เมื่อ `legalType=individual`|
|lastName |string(128) |Conditional |นามสกุล **จำเป็น** เมื่อ `legalType=individual`|
|companyName |string(256) |Conditional |ชื่อบริษัท / สถาบัน **จำเป็น** เมื่อ `legalType=company` |

### ความแตกต่างของฟิลด์ตามภูมิภาค

#### EU (MiCA / TFR)

ฟิลด์ที่ใช้ร่วมกัน บวกกับ:

| ฟิลด์ | ประเภท | จำเป็น | คำอธิบาย |
|:----- |:-----|:---------|:---------|
|transactionPurpose |string(20,500) |**true** |วัตถุประสงค์ของธุรกรรม อย่างน้อย 20 อักขระ |

#### TUR — ตุรกี (MASAK)

ฟิลด์ที่ใช้ร่วมกัน บวกกับฟิลด์เอกสาร POI ทั้งสี่ฟิลด์:

| ฟิลด์ | ประเภท | จำเป็น | คำอธิบาย |
|:----- |:-----|:---------|:---------|
|poiType |string(32) |**true** |ประเภทเอกสาร `ID_CARD` / `PASSPORT` / `DRIVERS` / `RESIDENCE_PERMIT` / `OTHER` |
|poiNumber |string(64) |**true** |เลขที่เอกสาร |
|poiIssuingCountry |string(10) |**true** |ประเทศที่ออกเอกสาร รหัสประเทศสามตัวอักษร |
|poiExpiredDate |string(20) |**true** |วันหมดอายุของเอกสาร `YYYY-MM-DD` |
|transactionPurpose |string(20,500) |**true** |วัตถุประสงค์ของธุรกรรม อย่างน้อย 20 อักขระ |

#### KAZ — คาซัคสถาน (AFSA)

ฟิลด์ที่ใช้ร่วมกัน บวกกับฟิลด์เอกสาร POI ทั้งสี่ฟิลด์:

| ฟิลด์ | ประเภท | จำเป็น | คำอธิบาย |
|:----- |:-----|:---------|:---------|
|poiType |string(32) |**true** |ประเภทเอกสาร `ID_CARD` / `PASSPORT` / `DRIVERS` / `RESIDENCE_PERMIT` / `OTHER` |
|poiNumber |string(64) |**true** |เลขที่เอกสาร |
|poiIssuingCountry |string(10) |**true** |ประเทศที่ออกเอกสาร รหัสประเทศสามตัวอักษร |
|poiExpiredDate |string(20) |**true** |วันหมดอายุของเอกสาร `YYYY-MM-DD` |

#### WaanX-IND — อินเดีย (FIU-IND)

ใช้เฉพาะฟิลด์ที่ใช้ร่วมกัน ไม่มีฟิลด์จำเป็นเพิ่มเติม

#### WaanX-KOR — เกาหลี (SAFA) — สำหรับการถอนเท่านั้น

ฟิลด์ที่ใช้ร่วมกัน บวกกับ:

| ฟิลด์ | ประเภท | จำเป็น | คำอธิบาย |
|:----- |:-----|:---------|:---------|
|representativeFirstName |string(128) |Conditional |ชื่อของผู้แทนบริษัท **จำเป็นเมื่อ `legalType=company`** (ข้อกำหนดของ SAFA เกาหลี) |
|representativeLastName |string(128) |Conditional |นามสกุลของผู้แทนบริษัท **จำเป็นเมื่อ `legalType=company`** (ข้อกำหนดของ SAFA เกาหลี) |

:::note
นิติบุคคลเกาหลีใน**ฝั่งการฝาก**ไม่ได้ใช้แบบสอบถามนี้ — จะจัดการแยกผ่านช่องทางธนาคารท้องถิ่น / CTP
:::

### ขอบเขตของเขตการกำกับดูแล

| รหัสนิติบุคคล | ภูมิภาค | การถอน | การฝาก | หมายเหตุ |
|:----------- |:-------|:----------:|:-------:|:------|
|EU |EU |✅ |✅ |MiCA / TFR |
|TUR |ตุรกี |✅ |✅ |MASAK — ต้องมี POI |
|KAZ |คาซัคสถาน |✅ |✅ |AFSA — ต้องมี POI |
|WaanX-IND |อินเดีย |✅ |✅ |FIU-IND |
|WaanX-KOR |เกาหลี |✅ |❌ |SAFA — การถอนต้องระบุผู้แทนบริษัท การฝากจัดการผ่านธนาคารท้องถิ่น / CTP |

### ตัวอย่าง

#### EU — บุคคลธรรมดา + กระเป๋าเงินแบบ Custodial
```json
{
  "walletType": 0,
  "vaspCode": "BINANCEUS_VASP",
  "legalType": "individual",
  "firstName": "John",
  "lastName": "Smith",
  "transactionPurpose": "Personal investment in long-term holdings"
}
```

#### TUR — บุคคลธรรมดา + กระเป๋าเงินแบบ Non-Custodial
```json
{
  "walletType": 1,
  "legalType": "individual",
  "firstName": "Ahmet",
  "lastName": "Yilmaz",
  "poiType": "ID_CARD",
  "poiNumber": "12345678901",
  "poiIssuingCountry": "TUR",
  "poiExpiredDate": "2030-06-15",
  "transactionPurpose": "Long-term holding for retirement savings purpose"
}
```

#### KAZ — นิติบุคคล + กระเป๋าเงินแบบ Custodial
```json
{
  "walletType": 0,
  "vaspCode": "EXAMPLE_VASP",
  "legalType": "company",
  "companyName": "Example LLC",
  "poiType": "OTHER",
  "poiNumber": "BIN1234567890",
  "poiIssuingCountry": "KAZ",
  "poiExpiredDate": "2099-12-31"
}
```

#### WaanX-IND — บุคคลธรรมดา + กระเป๋าเงินแบบ Non-Custodial
```json
{
  "walletType": 1,
  "legalType": "individual",
  "firstName": "Rahul",
  "lastName": "Sharma"
}
```

#### WaanX-KOR — นิติบุคคล + กระเป๋าเงินแบบ Custodial (สำหรับการถอนเท่านั้น)
```json
{
  "walletType": 0,
  "vaspCode": "EXAMPLE_VASP",
  "legalType": "company",
  "companyName": "Example Co., Ltd.",
  "representativeFirstName": "Min-jun",
  "representativeLastName": "Kim"
}
```
