## รหัส HTTP
|รหัส |คำอธิบาย |
|:----:|:-------------------------------|
|400|คำขอไม่ถูกต้อง ต้องส่งคำขอด้วย **GET** / **POST** (ต้องเป็นตัวพิมพ์ใหญ่)|
|401|คำขอไม่ถูกต้อง 1. ต้องใช้คีย์ที่ถูกต้องในการเข้าถึง 2. ต้องใส่พารามิเตอร์การยืนยันตัวตนไว้ใน request header |
|403|คำขอถูกปฏิเสธ สาเหตุที่เป็นไปได้: 1. เกินการจำกัดอัตราการเรียกต่อ IP 2. คุณส่งคำขอ GET พร้อมกับ json body ที่ว่างเปล่า 3. คุณใช้ IP ของสหรัฐอเมริกา|
|404|ไม่พบ path สาเหตุที่เป็นไปได้: 1. path ไม่ถูกต้อง 2. ค่า category ไม่ตรงกับโหมดบัญชี|
|429|การป้องกันความถี่ในระดับระบบ กรุณาลองใหม่เมื่อพบข้อผิดพลาดนี้|
