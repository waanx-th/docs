แก้ไขการตั้งค่าของคีย์ API ของบัญชีหลัก โดยใช้คีย์ API ที่ต้องการแก้ไขในการเรียกเอนด์พอยต์นี้ ใช้**คีย์ API ของบัญชีหลัก**ได้**เท่านั้น**

:::tip
คีย์ API ต้องมีสิทธิ์อย่างใดอย่างหนึ่งด้านล่างนี้จึงจะเรียกเอนด์พอยต์นี้ได้
* คีย์ API ของบัญชีหลัก: "Account Transfer", "Subaccount Transfer", "Withdrawal"
* สำหรับคีย์ API แบบ Read_Write ห้ามเพิ่มหรือลบ FiatP2P, FiatBitPay และ FiatConvertBroker
:::

:::info
แก้ไขได้เฉพาะคีย์ API ที่ใช้เรียกอินเทอร์เฟซนี้เท่านั้น
:::

### คำขอ HTTP
<APIEndpoint method="POST" url="/v5/user/update-api" />

### พารามิเตอร์คำขอ {#request-parameters}
| พารามิเตอร์ | จำเป็น | ประเภท | คำอธิบาย|
|:----- |:-------|:-----|------ |
|readOnly |false |integer |`0` (default): อ่านและเขียน `1`: อ่านเท่านั้น |
|permissions |false |Object |เลือกประเภทของสิทธิ์ ไม่ต้องส่งพารามิเตอร์นี้มาหากคุณไม่ต้องการเปลี่ยนสิทธิ์|
|> Spot |false |array |การเทรดสปอต ["SpotTrade"] |
|> Wallet |false |array |กระเป๋าเงิน ["AccountTransfer","SubMemberTransfer"] |
|> Exchange |false |array |การแปลงสกุลเงิน ["ExchangeHistory"] |
|> Earn |false |array |ผลิตภัณฑ์ Earn ["Earn"]|
|> FiatP2P |false |array |P2P ["FiatP2POrder", "Advertising"] |
|> FiatBitPay |false |array |WaanX Pay ["FaitPayOrder"] |
|> FiatConvertBroker |false |array |การแปลงเงิน fiat ["FiatConvertBrokerOrder"] |
|> BitCard |false|array |สิทธิ์ของบัตร WaanX, ["BitCard"]|
|> ByXPost |false|array |สิทธิ์การโพสต์ในคอมมูนิตี้, ["ByXPost"]|
|> Affiliate |false |array |สิทธิ์ของ Affiliate ["Affiliate"] <ul><li>สิทธิ์นี้มีประโยชน์เฉพาะกับ affiliate เท่านั้น</li><li>หากคุณต้องการสิทธิ์นี้ ต้องแน่ใจว่าได้ลบสิทธิ์อื่นทั้งหมดออกแล้ว</li></ul> |
|> BlockTrade |false |array |["BlockTrade"] |

### พารามิเตอร์การตอบกลับ {#response-parameters}
| พารามิเตอร์ | ประเภท | คำอธิบาย|
|:----- |:-----|----- |
|id |string |ID ที่ไม่ซ้ำกัน ใช้ภายในระบบ|
|note |string |หมายเหตุ |
|apiKey |string |คีย์ API |
|readOnly |integer |`0`: อ่านและเขียน `1`: อ่านเท่านั้น |
|secret |string |เป็น `""` เสมอ |
|permissions |Object |ประเภทของสิทธิ์ |
|> Spot |array |สิทธิ์ของสปอต |
|> Wallet |array |สิทธิ์ของกระเป๋าเงิน |
|> BlockTrade |array |สิทธิ์ของ blocktrade|
|> Exchange |array |สิทธิ์ของการแปลงสกุลเงิน |
|> Earn |array |สิทธิ์ของ Earn |
|> Affiliate |array |สิทธิ์ของ Affiliate|
|> FiatP2P |array |สิทธิ์ของ P2P|
|> FiatBitPay |array |สิทธิ์ของ WaanX Pay|
|> FiatConvertBroker |array |สิทธิ์ของการแปลงเงิน fiat|
|> NFT |array |**เลิกใช้งานแล้ว**, จะเป็น `[]` เสมอ|
|> CopyTrading |array |**เลิกใช้งานแล้ว**, จะเป็น `[]` เสมอ|
|ips |array |IP ที่ผูกไว้|
