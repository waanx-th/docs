แก้ไขการตั้งค่าของคีย์ API ของบัญชีย่อย โดยใช้คีย์ API ของบัญชีย่อยที่ต้องการแก้ไขในการเรียกเอนด์พอยต์นี้ หรือใช้คีย์ API ของ
บัญชีหลักเพื่อจัดการคีย์ API ของบัญชีย่อยที่อยู่ภายใต้

:::tip
คีย์ API ต้องมีสิทธิ์อย่างใดอย่างหนึ่งด้านล่างนี้จึงจะเรียกเอนด์พอยต์นี้ได้
* คีย์ API ของบัญชีย่อย: "Account Transfer", "Sub Member Transfer"
* คีย์ API ของบัญชีหลัก: "Account Transfer", "Sub Member Transfer", "Withdrawal"
:::

### คำขอ HTTP
<APIEndpoint method="POST" url="/v5/user/update-sub-api" />

### พารามิเตอร์คำขอ {#request-parameters}
| พารามิเตอร์ | จำเป็น | ประเภท | คำอธิบาย|
|:----- |:-------|:-----|------ |
|apikey |false |string |คีย์ API ของบัญชีย่อย <ul><li>คุณต้องส่งพารามิเตอร์นี้เมื่อใช้บัญชีหลักจัดการการตั้งค่าคีย์ API ของบัญชีย่อย</li><li>หากคุณใช้คีย์ API ของ UID บัญชีย่อยนั้นเรียกเอนด์พอยต์นี้ จะส่งพารามิเตอร์ `apikey` มาไม่ได้ มิฉะนั้นจะเกิดข้อผิดพลาด</li></ul> |
|readOnly |false |integer |`0` (default): อ่านและเขียน `1`: อ่านเท่านั้น |
|ips |false |string |กำหนด IP ที่ต้องการผูก ตัวอย่าง: `"192.168.0.1,192.168.0.2"`<b>หมายเหตุ:</b><ul><li>ไม่ส่ง ips มา หรือส่งเป็น `"*"` หมายถึงไม่ผูก IP</li><li>คีย์ API ที่ไม่ได้ผูก IP จะ<b>ใช้งานไม่ได้หลังจาก 90 วัน</b></li><li>คีย์ API จะใช้งานไม่ได้หลังจาก <b>7 วัน</b> เมื่อมีการเปลี่ยนรหัสผ่านของบัญชี</li></ul>|
|permissions |false |Object |เลือกประเภทของสิทธิ์ ไม่ต้องส่งพารามิเตอร์นี้มาหากคุณไม่ต้องการเปลี่ยนสิทธิ์|
|> Spot |false |array |การเทรดสปอต `["SpotTrade"]` |
|> Wallet |false |array |กระเป๋าเงิน `["AccountTransfer", "SubMemberTransferList"]`<br/>_หมายเหตุ: ยังไม่รองรับบัญชีแบบ fund custodial_|
|> Exchange |false |array |การแปลงสกุลเงิน `["ExchangeHistory"]` |
|> Earn |false |array |ผลิตภัณฑ์ Earn `["Earn"]` |

### พารามิเตอร์การตอบกลับ {#response-parameters}
| พารามิเตอร์ | ประเภท | คำอธิบาย|
|:----- |:-----|----- |
|id |string |ID ที่ไม่ซ้ำกัน ใช้ภายในระบบ|
|note |string |หมายเหตุ |
|apiKey |string |คีย์ API |
|readOnly |integer |`0`: อ่านและเขียน `1`: อ่านเท่านั้น |
|secret |string |เป็น `""` เสมอ |
|permissions |Object |ประเภทของสิทธิ์ |
|> Spot |array |สิทธิ์ของสปอต |
|> Wallet |array |สิทธิ์ของกระเป๋าเงิน |
|> Exchange |array |สิทธิ์ของการแปลงสกุลเงิน |
|> Earn |array |สิทธิ์ของ Earn |
|> BlockTrade |array |ไม่ใช้กับบัญชีย่อย จะเป็น `[]` เสมอ|
|> Affiliate |array |ไม่ใช้กับบัญชีย่อย จะเป็น `[]` เสมอ|
|> FiatP2P |array |ไม่ใช้กับบัญชีย่อย จะเป็น `[]` เสมอ|
|> FiatConvertBroker |array |ไม่ใช้กับบัญชีย่อย จะเป็น `[]` เสมอ|
|> NFT |array |**เลิกใช้งานแล้ว**, จะเป็น `[]` เสมอ|
|> CopyTrading |array |**เลิกใช้งานแล้ว**, จะเป็น `[]` เสมอ|
|ips |array |IP ที่ผูกไว้|
