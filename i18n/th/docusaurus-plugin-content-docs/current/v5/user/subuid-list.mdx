ดึง UID บัญชีย่อยของบัญชีหลักได้สูงสุด 1,000 รายการ หากคุณมีบัญชีย่อยมากกว่านี้ โปรดใช้ [ดึงรายการ UID บัญชีย่อย (ไม่จำกัด)](./page-subuid) ใช้**คีย์ API ของบัญชีหลัก**ได้**เท่านั้น**

:::tip
คีย์ API ต้องมีสิทธิ์อย่างใดอย่างหนึ่งด้านล่างนี้จึงจะเรียกเอนด์พอยต์นี้ได้
* คีย์ API ของบัญชีหลัก: "Account Transfer", "Subaccount Transfer", "Withdrawal"
:::

### คำขอ HTTP
<APIEndpoint method="GET" url="/v5/user/query-sub-members" />

### พารามิเตอร์คำขอ {#request-parameters}
ไม่มี

### พารามิเตอร์การตอบกลับ {#response-parameters}
| พารามิเตอร์ | ประเภท | คำอธิบาย|
|:----- |:-----|----- |
|subMembers |array |อ็อบเจกต์ |
|> uid |string |ID ผู้ใช้บัญชีย่อย |
|> username |string |ชื่อผู้ใช้|
|> memberType |integer |`1`: บัญชีย่อยทั่วไป, `6`: บัญชีย่อยแบบ custodial |
|> status |integer |สถานะของบัญชีผู้ใช้<ul><li>`1`: ปกติ</li><li>`2`: ห้ามเข้าสู่ระบบ</li><li>`4`: ถูกระงับ </li></ul>|
|> accountMode |integer |โหมดบัญชีของบัญชีผู้ใช้<ul><li>`3`: UTA1.0</li><li>`4`: UTA1.0 Pro</li><li>`5`: UTA2.0</li><li>`6`: UTA2.0 Pro</li></ul>|
|> remark |string |หมายเหตุ |
