### คำขอ HTTP
<APIEndpoint method="GET" url="/v5/user/invitation/referrals" />

### พารามิเตอร์คำขอ {#request-parameters}
| พารามิเตอร์ | จำเป็น | ประเภท | คำอธิบาย|
|:----- |:-------|:-----|------ |
|status |false |string |สถานะความสัมพันธ์ของการเชิญ, `0`: ใช้งานอยู่; `1`: ไม่ถูกต้อง โดยค่าเริ่มต้นจะคืนค่าทุกสถานะ|
|size |false |string |จำนวนข้อมูลต่อหนึ่งหน้า [1, 100] คืนค่า 20 รายการตามค่าเริ่มต้น|
|cursor |false |string |เคอร์เซอร์ ใช้โทเค็น `nextCursor` จากการตอบกลับเพื่อดึงผลลัพธ์หน้าถัดไป|

### พารามิเตอร์การตอบกลับ {#response-parameters}
| พารามิเตอร์ | ประเภท | คำอธิบาย|
|:----- |:-----|----- |
|nextCursor |string |ค่าเคอร์เซอร์ของหน้าถัดไป|
|records |array |Object|
|> id |string |ID, ใช้ภายในระบบ|
|> inviteeUid |string |userID ของผู้ที่ได้รับเชิญ|
|> status |integer |สถานะความสัมพันธ์ของการเชิญ, `0`: ใช้งานอยู่; `1`: ไม่ถูกต้อง|
|> createdAt |string |ประทับเวลาที่สร้าง|
|> updatedAt |string |ประทับเวลาที่อัปเดต|
