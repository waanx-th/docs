สอบถามรหัสผู้แนะนำที่ผู้ใช้ปัจจุบันเป็นเจ้าของ พร้อมลิงก์ลงทะเบียนผู้แนะนำที่สอดคล้องกัน

:::info
- บัญชีย่อยจะคืนค่ารหัสผู้แนะนำของบัญชีหลัก
- คืนค่าเฉพาะรหัสผู้แนะนำที่ยังใช้งานได้ (ยังไม่หมดอายุ) เท่านั้น
:::

### คำขอ HTTP
<APIEndpoint method="GET" url="/v5/user/invitation/code" />

### พารามิเตอร์คำขอ {#request-parameters}
ไม่ต้องใช้พารามิเตอร์คำขอ ระบบจะระบุตัวตนของผู้ใช้จากคีย์ API

### พารามิเตอร์การตอบกลับ {#response-parameters}
| พารามิเตอร์ | ประเภท | คำอธิบาย|
|:----- |:-----|----- |
|referralCodes |array |รายการรหัสผู้แนะนำที่ผู้ใช้เป็นเจ้าของ |
|> referralCode |string |สตริงของรหัสผู้แนะนำ |
|> referralLink |string |ลิงก์ลงทะเบียนผู้แนะนำสำหรับไซต์ของผู้ใช้ โครงสร้าง URL: `https://{domain}/{lang}/invite/?ref={referralCode}` |
|> scene |integer |ประเภทบริบทของรหัสผู้แนะนำ `1`: Affiliate; `2`: Friend |
