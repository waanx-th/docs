ลบคีย์ API ของบัญชีหลัก โดยใช้คีย์ API ที่ต้องการลบในการเรียกเอนด์พอยต์นี้ ใช้**คีย์ API ของบัญชีหลัก**ได้**เท่านั้น**

:::tip
คีย์ API ต้องมีสิทธิ์อย่างใดอย่างหนึ่งด้านล่างนี้จึงจะเรียกเอนด์พอยต์นี้ได้
* คีย์ API ของบัญชีหลัก: "Account Transfer", "Subaccount Transfer", "Withdrawal"
:::

:::danger
โปรดระวัง! คีย์ API ที่ใช้เรียกอินเทอร์เฟซนี้จะใช้งานไม่ได้ทันที
:::
