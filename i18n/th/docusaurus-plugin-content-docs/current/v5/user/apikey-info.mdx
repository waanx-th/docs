ดึงข้อมูลของคีย์ API โดยใช้คีย์ API ที่ต้องการตรวจสอบในการเรียกเอนด์พอยต์นี้ ใช้ได้ทั้ง**คีย์ API ของบัญชีหลักและของบัญชีย่อย**

:::tip
สิทธิ์ใดก็สามารถเข้าถึงเอนด์พอยต์นี้ได้
:::

### คำขอ HTTP
<APIEndpoint method="GET" url="/v5/user/query-api" />

### พารามิเตอร์คำขอ {#request-parameters}
ไม่มี

### พารามิเตอร์การตอบกลับ {#response-parameters}
| พารามิเตอร์ | ประเภท | คำอธิบาย|
|:----- |:-----|----- |
|id |string |ID ที่ไม่ซ้ำกัน ใช้ภายในระบบ|
|note |string |หมายเหตุ |
|apiKey |string |คีย์ API |
|readOnly |integer |`0`: อ่านและเขียน `1`: อ่านเท่านั้น |
|secret |string |เป็น `""` เสมอ |
|permissions |Object |ประเภทของสิทธิ์ |
|> Spot |array |สิทธิ์ของสปอต `SpotTrade` |
|> Wallet |array |สิทธิ์ของกระเป๋าเงิน `AccountTransfer`, `SubMemberTransfer`(บัญชีหลัก), `SubMemberTransferList`(บัญชีย่อย), `Withdraw`(บัญชีหลัก)|
|> Exchange |array |สิทธิ์ของการแปลงสกุลเงิน `ExchangeHistory` |
|> Earn |array |สิทธิ์ของผลิตภัณฑ์ Earn `Earn` |
|> FiatP2P |array |สิทธิ์ของ P2P `FiatP2POrder`, `Advertising` ไม่ใช้กับบัญชีย่อย จะเป็น `[]` เสมอ|
|> FiatBitPay |array |สิทธิ์ของ WaanX Pay `FaitPayOrder` ไม่ใช้กับบัญชีย่อย จะเป็น `[]` เสมอ|
|> FiatConvertBroker |array |สิทธิ์ของการแปลงเงิน fiat `FiatConvertBrokerOrder` ไม่ใช้กับบัญชีย่อย จะเป็น `[]` เสมอ|
|> BitCard |array |สิทธิ์ของบัตร WaanX, `BitCard` ไม่ใช้กับบัญชีย่อย|
|> ByXPost |array |สิทธิ์การโพสต์ในคอมมูนิตี้, `ByXPost` ไม่ใช้กับบัญชีย่อย|
|> Affiliate |array |สิทธิ์ของ Affiliate เฉพาะ affiliate เท่านั้นที่มีสิทธิ์นี้ได้ กรณีอื่นจะเป็น `[]` เสมอ |
|> BlockTrade |array |สิทธิ์ของ blocktrade ไม่ใช้กับบัญชีย่อย จะเป็น `[]` เสมอ|
|> NFT |array |**เลิกใช้งานแล้ว**, จะเป็น `[]` เสมอ |
|> CopyTrading |array |**เลิกใช้งานแล้ว**, จะเป็น `[]` เสมอ |
|ips |array |IP ที่ผูกไว้|
|type |integer |ประเภทของคีย์ API `1`: ส่วนบุคคล, `2`: เชื่อมต่อกับแอปของบุคคลที่สาม |
|deadlineDay |integer |จำนวนวันที่เหลือที่คีย์ API ยังใช้งานได้ ใช้เฉพาะกับคีย์ API ที่ไม่ได้ผูก IP หรือมีการเปลี่ยนรหัสผ่านแล้ว |
|expiredAt |datetime |วันหมดอายุของคีย์ API ใช้เฉพาะกับคีย์ API ที่ไม่ได้ผูก IP หรือมีการเปลี่ยนรหัสผ่านแล้ว|
|createdAt |datetime |วันที่สร้างคีย์ API |
|uta |integer |บัญชีดังกล่าวได้อัปเกรดเป็นบัญชีเทรดแบบ unified หรือไม่ `1`: บัญชีเทรดแบบ unified |
|userID |integer |ID ผู้ใช้ |
|inviterID |integer |ID ของผู้เชิญ (UID ของบัญชีที่เชิญบัญชีนี้เข้าสู่แพลตฟอร์ม) |
|[vipLevel](../enum#viplevel) |string |ระดับ VIP |
|mktMakerLevel |string |ระดับ market maker |
|affiliateID |integer |ID ของ Affiliate `0` หมายถึงไม่มีความสัมพันธ์ที่ผูกไว้ |
|rsaPublicKey |string |คีย์สาธารณะ RSA |
|isMaster |boolean |คีย์ API นี้เป็นของบัญชีหลักหรือไม่ |
|parentUid |string |UID ของบัญชีหลัก จะคืนค่า `"0"` เมื่อเรียกเอนด์พอยต์นี้ด้วยบัญชีหลัก |
|kycLevel |string |ระดับ KYC ของบัญชีส่วนบุคคล `LEVEL_DEFAULT`, `LEVEL_1`, `LEVEL_2` |
|kycRegion |string |ภูมิภาค KYC ของบัญชีส่วนบุคคล |
|unified |integer |**เลิกใช้งานแล้ว**|
