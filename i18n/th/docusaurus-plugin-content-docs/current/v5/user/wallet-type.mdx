ดึงประเภทกระเป๋าเงินที่ใช้ได้ของบัญชีหลักหรือบัญชีย่อย

:::tip
* คีย์ API ของบัญชีหลัก: ดึงประเภทกระเป๋าเงินที่ใช้ได้ของบัญชีหลักและของบัญชีย่อยที่ระบุได้ และรองรับได้สูงสุด 200 UID บัญชีย่อยในหนึ่งคำขอ
* คีย์ API ของบัญชีย่อย: ดึงประเภทกระเป๋าเงินที่ใช้ได้ของตัวเองได้
:::

### คำขอ HTTP
<APIEndpoint method="GET" url="/v5/user/get-member-type" />

### พารามิเตอร์คำขอ {#request-parameters}
| พารามิเตอร์ | จำเป็น | ประเภท | คำอธิบาย|
|:----- |:-------|:-----|------ |
|memberIds |false |string |<ul><li>สอบถามประเภทกระเป๋าเงินของตัวเองเมื่อไม่ส่งค่านี้มา</li><li>เมื่อใช้คีย์ API ของบัญชีหลักสอบถาม UID บัญชีย่อย ข้อมูลของ UID บัญชีหลักจะถูกคืนค่าไว้ที่ต้นอาร์เรย์เสมอ</li><li>รองรับ UID บัญชีย่อยหลายรายการ คั่นด้วยเครื่องหมายจุลภาค</li><li>พารามิเตอร์นี้จะถูกละเว้นเมื่อคุณใช้คีย์ API ของบัญชีย่อย</li></ul>|

### พารามิเตอร์การตอบกลับ {#response-parameters}
| พารามิเตอร์ | ประเภท | คำอธิบาย|
|:----- |:-----|----- |
|accounts |array |อ็อบเจกต์ |
|> uid |string |ID ผู้ใช้ของบัญชีหลัก/บัญชีย่อย |
|> [accountType](../enum#accounttype) |array |อาร์เรย์ของกระเป๋าเงิน `FUND`,`UNIFIED`|
