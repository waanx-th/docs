## URL
`wss://stream.waanx.com/v5/trade`

## ขอบเขต
* **รองรับ**: สปอต
* **ไม่รองรับ**: การเทรดแบบเดโม

## การยืนยันตัวตน {#authentication}
### พารามิเตอร์คำขอ {#request-parameters}
| พารามิเตอร์ | จำเป็น | ประเภท | คำอธิบาย|
|:----- |:-------|:-----|------ |
|reqId|false |string |ฟิลด์ที่ไม่จำเป็น ใช้สำหรับจับคู่กับการตอบกลับ <ul><li>หากไม่ส่งมา ฟิลด์นี้จะไม่ถูกคืนค่าในการตอบกลับ</li></ul>|
|op |**true** |string |ประเภท op `auth`|
|args |**true** |string |["api key", expiry timestamp, "signature"] โปรดคลิก[ที่นี่](/v5/ws/connect#authentication)เพื่อสร้างลายเซ็น |

### พารามิเตอร์การตอบกลับ {#response-parameters}
| พารามิเตอร์ | ประเภท | คำอธิบาย|
|:----- |:-----|----- |
|reqId |string |<ul><li>หากส่งค่านี้มาในคำขอ ก็จะถูกคืนค่าในการตอบกลับ</li><li>หากไม่ได้ส่งมา ก็จะไม่ถูกคืนค่าในการตอบกลับ</li></ul>|
|retCode |integer |<ul><li>`0`: ยืนยันตัวตนสำเร็จ</li><li>`20001`: ยืนยันตัวตนซ้ำ</li><li>`10004`: ลายเซ็นไม่ถูกต้อง</li><li>`10001`: พารามิเตอร์ผิดพลาด</li></ul>|
|retMsg |string |<ul><li>`OK`</li><li>ข้อความข้อผิดพลาด</li></ul> |
|op |string |ประเภท op |
|connId |string |รหัสการเชื่อมต่อ ซึ่งเป็นรหัสที่ไม่ซ้ำกันของการเชื่อมต่อนั้น |

### ตัวอย่างคำขอ
```json
{
    "op": "auth",
    "args": [
        "XXXXXX",
        1711010121452,
        "ec71040eff72b163a36153d770b69d6637bcb29348fbfbb16c269a76595ececf"
    ]
}
```

### ตัวอย่างการตอบกลับ
```json
{
    "retCode": 0,
    "retMsg": "OK",
    "op": "auth",
    "connId": "cnt5leec0hvan15eukcg-2t"
}
```

## สร้าง/แก้ไข/ยกเลิกคำสั่งซื้อขาย
### พารามิเตอร์คำขอ
| พารามิเตอร์ | จำเป็น | ประเภท | คำอธิบาย|
|:----- |:-------|:-----|------ |
|reqId|false |string |ใช้ระบุความไม่ซ้ำกันของคำขอ เมื่อส่งค่านี้มา การตอบกลับจะคืนค่านี้ให้ ความยาวต้องไม่เกิน 36 อักขระ <ul><li>หากส่งมา ค่านี้ต้องไม่ซ้ำกัน มิฉะนั้นคุณจะได้รับ "20006"</li></ul>|
|header|**true** |object |เฮดเดอร์ของคำขอ|
|> X-BAPI-TIMESTAMP|**true** |string |ประทับเวลาปัจจุบัน|
|> X-BAPI-RECV-WINDOW|false |string |ค่าเริ่มต้นคือ 5000(ms) คำขอจะถูกปฏิเสธเมื่อไม่เป็นไปตามกฎนี้: <i>WaanX_server_time - X-BAPI-RECV-WINDOW &lt;= X-BAPI-TIMESTAMP &lt; WaanX_server_time + 1000</i>|
|> Referer|false |string |ตัวระบุ referer สำหรับผู้ใช้ API broker|
|op |**true** |string |ประเภท op <ul><li>`order.create`: สร้างคำสั่งซื้อขาย</li> <li>`order.amend`: แก้ไขคำสั่งซื้อขาย</li> <li>`order.cancel`: ยกเลิกคำสั่งซื้อขาย</li></ul>|
|args |**true** |array&ltobject&gt |อาร์เรย์ args ปัจจุบันรองรับเพียงหนึ่งรายการเท่านั้น <ul><li>`order.create`: ดู[คำขอสร้างคำสั่งซื้อขาย](../../order/create-order#request-parameters)</li><li>`order.amend`: ดู[คำขอแก้ไขคำสั่งซื้อขาย](../../order/amend-order#request-parameters)</li><li>`order.cancel`: ดู[คำขอยกเลิกคำสั่งซื้อขาย](../../order/cancel-order#request-parameters)</li></ul> |

### พารามิเตอร์การตอบกลับ
| พารามิเตอร์ | ประเภท | คำอธิบาย|
|:----- |:-----|----- |
|reqId |string |<ul><li>หากส่งค่านี้มาในคำขอ ก็จะถูกคืนค่าในการตอบกลับ</li><li>หากไม่ได้ส่งมา ก็จะไม่ถูกคืนค่าในการตอบกลับ</li></ul>|
|retCode |integer |<ul><li>`0`: สำเร็จ</li><li>`10403`: เกินการจำกัดอัตราการเรียกของ IP โดยจำกัดที่ 3000 คำขอต่อวินาทีต่อหนึ่ง IP</li><li>`10404`: 1. ไม่พบประเภท op; 2. `category` ไม่ถูกต้องหรือไม่รองรับ</li><li>`10429`: การป้องกันความถี่ในระดับระบบ</li><li>`20006`: reqId ซ้ำกัน</li><li>`10016`: 1. เกิดข้อผิดพลาดภายในเซิร์ฟเวอร์; 2. บริการกำลังรีสตาร์ต</li><li>`10019`: บริการเทรดผ่าน ws กำลังรีสตาร์ต จึงไม่รับคำขอใหม่ แต่คำขอที่กำลังดำเนินการอยู่จะไม่ได้รับผลกระทบ คุณสามารถสร้างการเชื่อมต่อใหม่เพื่อให้ถูกกำหนดเส้นทางไปยังบริการที่ทำงานปกติได้</li></ul>|
|retMsg |string |<ul><li>`OK`</li><li>`""`</li><li>ข้อความข้อผิดพลาด</li></ul> |
|op |string |ประเภท op |
|data |object |ข้อมูลทางธุรกิจ เหมือนกับ `result` ในการตอบกลับของ rest api <ul><li>`order.create`: ดู[การตอบกลับของการสร้างคำสั่งซื้อขาย](../../order/create-order#response-parameters)</li><li>`order.amend`: ดู[การตอบกลับของการแก้ไขคำสั่งซื้อขาย](../../order/amend-order#response-parameters)</li><li>`order.cancel`: ดู[การตอบกลับของการยกเลิกคำสั่งซื้อขาย](../../order/cancel-order#response-parameters)</li></ul> |
|retExtInfo|object |เป็นอ็อบเจกต์ว่างเสมอ|
|header |object |ข้อมูลเฮดเดอร์ |
|> TraceId |string |รหัสติดตาม ใช้ติดตามเส้นทางของคำขอ |
|> Timenow |string |ประทับเวลาปัจจุบัน |
|> X-Bapi-Limit |string |การจำกัดอัตราการเรียกทั้งหมดของบัญชีปัจจุบันสำหรับประเภท op นี้ |
|> X-Bapi-Limit-Status |string |การจำกัดอัตราการเรียกที่เหลือของบัญชีปัจจุบันสำหรับประเภท op นี้ |
|> X-Bapi-Limit-Reset-Timestamp |string |ประทับเวลาที่ระบุว่าการจำกัดคำขอของคุณจะรีเซ็ตเมื่อใด หากคุณใช้เกินการจำกัดอัตราการเรียกแล้ว หากไม่เกิน ค่านี้ก็เป็นเพียงประทับเวลาปัจจุบัน (ซึ่งอาจไม่ตรงกับ `timeNow` เป๊ะ ๆ)|
|connId |string |รหัสการเชื่อมต่อ ซึ่งเป็นรหัสที่ไม่ซ้ำกันของการเชื่อมต่อนั้น |

:::info
การตอบรับ (ack) ของคำขอสร้าง/แก้ไข/ยกเลิกคำสั่งซื้อขายบ่งบอกว่าคำขอถูกรับไว้เรียบร้อยแล้ว โปรดใช้สตรีมคำสั่งซื้อขายผ่าน websocket เพื่อยืนยันสถานะของคำสั่งซื้อขาย
:::

## สร้าง/แก้ไข/ยกเลิกคำสั่งซื้อขายแบบกลุ่ม
:::info
* สามารถสร้างคำสั่งซื้อขายได้สูงสุด 10 รายการ (สปอต) ต่อหนึ่งคำขอ รายการข้อมูลที่คืนค่ามาจะถูกแบ่งเป็นสองรายการ รายการแรกระบุว่าการสร้างคำสั่งซื้อขายสำเร็จหรือไม่ และรายการที่สองแสดงรายละเอียดข้อมูลของคำสั่งซื้อขายที่สร้างขึ้น โครงสร้างของทั้งสองรายการสอดคล้องกันทั้งหมด
- **คำอธิบายการจำกัดอัตราการเรียกของสปอต** โปรดดู[กฎการจำกัดอัตราการเรียก](../../rate-limit/rules-for-vips)
* การจำกัดอัตราการเรียกระดับบัญชีถูกใช้ร่วมกันระหว่างคำสั่งซื้อขายแบบกลุ่มผ่าน websocket และ http
* การตอบรับคำขอสร้าง/แก้ไข/ยกเลิกคำสั่งซื้อขายแบบกลุ่มบ่งบอกว่าคำขอถูกรับไว้เรียบร้อยแล้ว คำขอนี้ทำงานแบบอะซิงโครนัส ดังนั้นโปรดใช้ websocket เพื่อยืนยันสถานะของคำสั่งซื้อขาย
:::

## Ping
### พารามิเตอร์คำขอ
| พารามิเตอร์ | จำเป็น | ประเภท | คำอธิบาย|
|:----- |:-------|:-----|------ |
|op |**true** |string |ประเภท op `ping`|

### พารามิเตอร์การตอบกลับ
| พารามิเตอร์ | ประเภท | คำอธิบาย|
|:----- |:-----|----- |
|retCode |integer |รหัสผลลัพธ์|
|retMsg |string |ข้อความผลลัพธ์ |
|op |string |ประเภท op `pong` |
|data |array |มีหนึ่งรายการในอาร์เรย์ คือประทับเวลาปัจจุบัน (string)|
|connId |string |รหัสการเชื่อมต่อ ซึ่งเป็นรหัสที่ไม่ซ้ำกันของการเชื่อมต่อนั้น |
