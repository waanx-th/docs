สมัครรับข้อมูลสตรีมทิกเกอร์

:::note
* หัวข้อนี้ใช้ฟิลด์ snapshot และฟิลด์ delta หากไม่พบพารามิเตอร์การตอบกลับใดในข้อความ หมายความว่าค่าของพารามิเตอร์นั้นไม่มีการเปลี่ยนแปลง
* ข้อความทิกเกอร์ของสปอตเป็น `snapshot` **เท่านั้น**
:::
ความถี่ในการส่งข้อมูล: **50ms**

**หัวข้อ:**<br/>
`tickers.{symbol}`

### พารามิเตอร์การตอบกลับ {#response-parameters}

    </tr>

    </tr>
    <tr>
        <td>ts</td><td>number</td><td>ประทับเวลา (มิลลิวินาที) ที่ระบบสร้างข้อมูลนี้</td>
    </tr>
    <tr>
        <td>type</td><td>string</td><td>ประเภทข้อมูล <code>snapshot</code></td>
    </tr>
    <tr>
        <td>cs</td><td>integer</td><td>ลำดับแบบครอส</td>
    </tr>
    <tr>
        <td>data</td><td>array</td><td>อ็อบเจกต์</td>
    </tr>
    <tr>
        <td>> symbol</td><td>string</td><td>ชื่อสัญลักษณ์คู่เทรด </td>
    </tr>
    <tr>
        <td>> lastPrice</td><td>string</td><td>ราคาล่าสุด </td>
    </tr>
    <tr>
        <td>> highPrice24h</td><td>string</td><td>ราคาสูงสุดใน 24 ชั่วโมงที่ผ่านมา </td>
    </tr>
    <tr>
        <td>> lowPrice24h</td><td>string</td><td>ราคาต่ำสุดใน 24 ชั่วโมงที่ผ่านมา </td>
    </tr>

    </tr>
    <tr>

        <td>> price24hPcnt</td><td>string</td><td>เปอร์เซ็นต์การเปลี่ยนแปลงของราคาตลาดเทียบกับ 24 ชั่วโมง </td>
    </tr>
    <tr>
        <td>> usdIndexPrice</td><td>string</td><td>ราคาดัชนี USD <ul><li>ใช้คำนวณมูลค่า USD ของสินทรัพย์ในบัญชี Unified</li><li>เหรียญมาร์จิ้นที่ไม่ใช่หลักประกันจะคืนค่าเป็น ""</li></ul></td>
    </tr>
</table>
