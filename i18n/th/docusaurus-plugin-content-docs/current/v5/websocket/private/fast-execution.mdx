สตรีมการจับคู่แบบเร็วช่วยลดความหน่วงของข้อมูลได้อย่างมากเมื่อเทียบกับสตรีม "execution" เดิม อย่างไรก็ตาม สตรีมนี้จะส่งข้อมูล 
การจับคู่เพียงบางประเภทเท่านั้น และมีฟิลด์ข้อมูลน้อยกว่า

**หัวข้อรวมทุกหมวดหมู่:** `execution.fast`<br/>
**หัวข้อแยกตามหมวดหมู่:** `execution.fast.spot`<br/>

:::info
* รองรับการจับคู่ในตลาดสปอต
* คุณจะได้รับเฉพาะการอัปเดตที่ [execType](../../enum#exectype)=Trade เท่านั้น
:::

### พารามิเตอร์การตอบกลับ {#response-parameters}
| พารามิเตอร์ | ประเภท | คำอธิบาย|
|:----- |:-----|----- |
|topic |string |ชื่อหัวข้อ |
|creationTime |number |ประทับเวลาที่สร้างข้อมูล (มิลลิวินาที) |
|data |array |อ็อบเจกต์ |
|> [category](../../enum#category) | string | ประเภทผลิตภัณฑ์ `spot`|
|> symbol |string   |ชื่อสัญลักษณ์คู่เทรด |
|> orderId |string |รหัสคำสั่งซื้อขาย |
|> isMaker |boolean |`true`: Maker, `false`: Taker |
|> orderLinkId |string |รหัสคำสั่งซื้อขายที่ผู้ใช้กำหนดเอง <ul><li>การเทรดฝั่ง maker จะเป็น `""` เสมอ</li><li>หากคำสั่งฝั่ง maker ในสมุดคำสั่งซื้อขายถูกเปลี่ยนเป็นฝั่ง taker (ด้วยการแก้ไขราคา) ค่า orderLinkId จะเป็น `""` เช่นกัน</li></ul> |
|> execId |string |รหัสการจับคู่ |
|> execPrice |string |ราคาที่จับคู่ |
|> execQty |string |จำนวนที่จับคู่ |
|> side |string |ทิศทาง `Buy`,`Sell` |
|> execTime |string |ประทับเวลาที่จับคู่ (มิลลิวินาที)  |
|> seq |long |ลำดับแบบครอส ใช้เชื่อมโยงการจับคู่แต่ละครั้งกับการอัปเดตสถานะแต่ละครั้ง<ul><li>ค่า seq จะเหมือนกันเมื่อมีการจับคู่หลายรายการในเวลาเดียวกัน</li><li>สัญลักษณ์คู่เทรดที่ต่างกันอาจมีค่า seq เหมือนกัน โปรดใช้ seq + symbol เพื่อตรวจสอบความไม่ซ้ำกัน</li></ul>|

### ตัวอย่างการสมัครรับข้อมูล
```json
{
    "op": "subscribe",
    "args": [
        "execution.fast"
    ]
}
```
