สมัครรับข้อมูลสตรีม dcp เพื่อเปิดใช้งานฟังก์ชัน DCP

ตัวอย่างเช่น การเชื่อมต่อ A สมัครรับ "dcp.xxx" การเชื่อมต่อ B ไม่ได้สมัครรับ และการเชื่อมต่อ C สมัครรับ "dcp.xxx"
1. หาก A ยังทำงานอยู่ B หลุดไปแล้ว C ยังทำงานอยู่ กรณีนี้จะไม่ทริกเกอร์ DCP
2. หาก A ยังทำงานอยู่ B หลุดไปแล้ว C หลุดไปแล้ว กรณีนี้จะไม่ทริกเกอร์ DCP
3. หาก A หลุดไปแล้ว B ยังทำงานอยู่ C หลุดไปแล้ว DCP จะถูกทริกเกอร์เมื่อถึงเกณฑ์ timeWindow

สรุปคือ หากการเชื่อมต่อแบบ private ทั้งหมดที่สมัครรับหัวข้อ "dcp" หลุดไปทั้งหมด DCP ก็จะถูกทริกเกอร์

**หัวข้อ:** `dcp.spot`

### ตัวอย่างการสมัครรับข้อมูล
```json
{
    "op": "subscribe",
    "args": [
        "dcp.spot"
    ]
}
```
