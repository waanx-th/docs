คุณสามารถกำหนดได้ว่าระบบจะทำอย่างไรเมื่อราคาคำสั่งซื้อขายแบบลิมิตของคุณเกินราคาเสนอซื้อสูงสุดหรือราคาเสนอขายต่ำสุด
คุณสามารถเรียกดูการตั้งค่าปัจจุบันของคุณได้ด้วย [ดูการตั้งค่าพฤติกรรมการเทรด](/v5/account/get-user-setting-config)
ดูข้อมูลเพิ่มเติมเกี่ยวกับ[การจำกัดราคา](https://support.waanx.com/en/support/home) ได้ที่ศูนย์ช่วยเหลือ

---

โดย x% คือ [priceLimitRatioX](/v5/market/instrument) และ y% คือ [priceLimitRatioY](/v5/market/instrument):

* **ราคาซื้อสูงสุด**: *Min[Max(Index Price, Index Price × (1 + x%) + 2-Minute Average Premium), Index Price × (1 + y%)]*
* **ราคาขายต่ำสุด**: *Max[Min(Index Price, Index Price × (1 – x%) + 2-Minute Average Premium), Index Price × (1 – y%)]*

:::info การตั้งค่าเริ่มต้น
**modifyEnable = false.** หากราคาคำสั่งซื้อขายเกินขอบเขตที่กำหนด ระบบจะปฏิเสธคำขอนั้น <br/>
สอดคล้องกับ [ดูพฤติกรรมการจำกัดราคา](./get-user-setting-config) ซึ่ง **lpaSpot = false**
:::

### คำขอ HTTP
<APIEndpoint method="POST" url="/v5/account/set-limit-px-action" />

### พารามิเตอร์คำขอ {#request-parameters}
| พารามิเตอร์ | จำเป็น | ประเภท | คำอธิบาย|
|:----- |:-------|:-----|------ |
|category |**true** |string |`spot`|
|modifyEnable |**true** |boolean |`true`: อนุญาตให้ระบบแก้ไขราคาคำสั่งซื้อขาย<br/>`false`: ปฏิเสธคำขอคำสั่งซื้อขายของคุณ|

### พารามิเตอร์การตอบกลับ {#response-parameters}
ไม่มี
