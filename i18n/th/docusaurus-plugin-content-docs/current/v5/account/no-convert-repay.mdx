:::info
* เมื่อมีการส่ง `coin` และ `amount` จะมีการตรวจสอบต่อไปนี้ตาม `repaymentType`:
  * `ALL`: คำขอจะถูกปฏิเสธหาก `amount` เกินหนี้สินรวม
  * `FIXED`: คำขอจะถูกปฏิเสธหาก `amount` เกินหนี้สินอัตราคงที่
  * `FLEXIBLE`: คำขอจะถูกปฏิเสธหาก `amount` เกินหนี้สินอัตราลอยตัว
* เมื่อมีการส่ง `coin` แต่ไม่ส่ง `amount` การชำระคืนจะใช้ยอดคงเหลือที่ใช้ได้ในสปอตของเหรียญนั้น:
  * `FLEXIBLE`: ชำระคืนเฉพาะหนี้สินอัตราลอยตัวของเหรียญนั้น
  * `FIXED`: ชำระคืนเฉพาะหนี้สินอัตราคงที่ของเหรียญนั้น
  * `ALL`: ชำระคืนหนี้สินทั้งหมดของเหรียญนั้น (อัตราลอยตัวก่อน แล้วจึงอัตราคงที่)
:::

:::note สำคัญ
1. เมื่อชำระคืน ระบบจะใช้เฉพาะยอดคงเหลือที่ใช้ได้ในสปอตของสกุลเงินที่เป็นหนี้ ผู้ใช้สามารถชำระคืนด้วยตนเองได้โดยไม่ต้องแปลงสินทรัพย์อื่น
2. หากต้องการตรวจสอบจำนวนที่ใช้ได้ในสปอตสำหรับการชำระคืน คุณสามารถเรียก API นี้: ดึงจำนวนที่ใช้ได้สำหรับการชำระคืน
3. ห้ามชำระคืนระหว่างเวลา 04:00 ถึง 05:30 ของทุกชั่วโมง ดอกเบี้ยคำนวณจาก BorrowAmount ณ เวลา 05:00 ของทุกชั่วโมง
4. ระบบจะชำระคืนหนี้สินอัตราลอยตัวก่อน แล้วจึงเป็นอัตราคงที่
5. ตั้งแต่วันที่ 17 มีนาคม 2026 (ทยอยเปิดใช้ และเปิดใช้เต็มรูปแบบวันที่ 24 มีนาคม 2026) BYUSDT สามารถใช้สำหรับการชำระคืนได้
6. พฤติกรรมการตอบกลับของ API ตาม `repaymentType`: `FIXED`: อะซิงโครนัส; `FLEXIBLE`: ซิงโครนัส; `ALL`: อะซิงโครนัส
:::

### คำขอ HTTP
<APIEndpoint method="POST" url="/v5/account/no-convert-repay" />

### พารามิเตอร์คำขอ {#request-parameters}
| พารามิเตอร์ | จำเป็น | ประเภท | คำอธิบาย|
|:----- |:-------|:-----|------ |
|coin |**true** |string |ชื่อเหรียญ ตัวพิมพ์ใหญ่เท่านั้น|
|amount |false |string |จำนวนที่ชำระคืน หากไม่ส่ง `coin` ในพารามิเตอร์นำเข้า ก็ไม่สามารถส่ง `amount` ในพารามิเตอร์นำเข้าได้|
|repaymentType |false |string |ประเภทการชำระคืน `ALL`: ชำระคืนทั้งหนี้สินอัตราคงที่และอัตราลอยตัว โดยชำระอัตราลอยตัวก่อน; `FIXED`: ชำระคืนเฉพาะหนี้สินอัตราคงที่; `FLEXIBLE`: ชำระคืนเฉพาะหนี้สินอัตราลอยตัว ค่าเริ่มต้น: `FLEXIBLE`|

### พารามิเตอร์การตอบกลับ {#response-parameters}
| พารามิเตอร์ | ประเภท | คำอธิบาย|
|:----- |:-----|----- |
|result |array |Object |
|> resultStatus |string |<ul><li>`P`: กำลังดำเนินการ</li><li>`SU`: สำเร็จ</li><li>`FA`: ไม่สำเร็จ</li></ul>|
