คุณสามารถชำระคืนหนี้สินของบัญชี Unified ด้วยตนเองได้
> **สิทธิ์**: USDC Contracts<br/>

:::warning
API นี้ไม่รองรับการชำระคืนหนี้สินจากการกู้ด้วยตนเอง หากคุณพยายามทำเช่นนั้น จะได้รับข้อผิดพลาดต่อไปนี้:
```json
{
    "retCode": 182120,
    "retMsg": "Please use the repay and no-convert-repay API."
}
```
โปรดใช้ [ชำระคืนด้วยตนเอง](/v5/account/repay) (`/v5/account/repay`) หรือ [ชำระคืนด้วยตนเองโดยไม่แปลงสินทรัพย์](/v5/account/no-convert-repay) (`/v5/account/no-convert-repay`) เพื่อชำระคืนหนี้สินจากการกู้ด้วยตนเอง
:::

:::info
1. ตั้งแต่วันที่ 17 มีนาคม 2026 (ทยอยเปิดใช้ และเปิดใช้เต็มรูปแบบวันที่ 24 มีนาคม 2026) BYUSDT สามารถใช้สำหรับการชำระคืนได้
2. MNT จะยังไม่ถูกใช้สำหรับการชำระคืนเป็นการชั่วคราว และไม่รองรับการชำระคืนหนี้สิน MNT ผ่าน convert-repay อย่างไรก็ตาม คุณยังสามารถใช้ [ชำระคืนด้วยตนเองโดยไม่แปลงสินทรัพย์](/v5/account/no-convert-repay) เพื่อชำระคืน MNT ด้วยยอดคงเหลือที่คุณมีอยู่ได้
3. ตั้งแต่วันที่ 10 กุมภาพันธ์ 2026 เวลา 08:00 UTC การชำระคืนด้วยตนเองของ UTA Loan จะถูกปรับให้คำนวณค่าธรรมเนียมการชำระคืนแบบแปลงเหรียญโดยใช้อัตราค่าธรรมเนียมที่สูงกว่าระหว่างสินทรัพย์หลักประกันและสินทรัพย์ที่เป็นหนี้ และกำหนดวงเงินการแปลงเหรียญต่อรายการไม่เกิน USD 300,000 (จำนวนการแปลงเหรียญรวมต้องน้อยกว่า 300,000 USD เทียบเท่า) เพื่อเสริมความมั่นคงและการควบคุมความเสี่ยง โปรดดู [การอัปเดตการชำระคืนด้วยตนเองของ UTA Loan](https://waanx.com/en/gb/announcements) 
:::

### คำขอ HTTP
<APIEndpoint method="POST" url="/v5/account/quick-repayment" />

### พารามิเตอร์คำขอ {#request-parameters}
| พารามิเตอร์ | จำเป็น | ประเภท | คำอธิบาย|
|:----- |:-------|:-----|------ |
|coin |false |string |เหรียญที่มีหนี้สิน ตัวพิมพ์ใหญ่เท่านั้น <ul><li>ระบุเหรียญที่ต้องการ: ชำระคืนหนี้สินของเหรียญนั้นเป็นการเฉพาะ</li><li>ไม่ระบุเหรียญ: ชำระคืนหนี้สินของทุกเหรียญ</li></ul>|

### พารามิเตอร์การตอบกลับ {#response-parameters}
| พารามิเตอร์ | ประเภท | คำอธิบาย|
|:----- |:-----|----- |
|list |array |Object|
|> coin |string |เหรียญที่ใช้ชำระคืน <ul><li>ลำดับของสกุลเงินที่ใช้ชำระคืนหนี้สินอ้างอิงจาก `liquidationOrder` ของเอนด์พอยต์นี้</li></ul>|
|> repaymentQty |string |จำนวนที่ชำระคืน|
