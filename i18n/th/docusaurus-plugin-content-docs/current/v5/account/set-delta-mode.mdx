โหมด Delta Neutral ออกแบบมาเพื่อยกระดับประสบการณ์การเทรดของผู้ใช้ที่ใช้กลยุทธ์แบบ delta-neutral เมื่อเปิดใช้งาน โพซิชันที่เข้าเกณฑ์ Delta Neutral จะถูกจัดอันดับให้อยู่ลำดับท้ายกว่าในคิว ADL (Auto-Deleveraging) ซึ่งช่วยลดความเสี่ยงที่จะถูกลดเลเวอเรจโดยอัตโนมัติในสภาวะตลาดที่ผันผวนรุนแรง 
ดูรายละเอียดเพิ่มเติมได้จากบทความช่วยเหลือ [Delta Neutral Mode](https://support.waanx.com/en/support/home)

คุณสามารถเปิด/ปิดโหมด Delta Neutral ได้ หากต้องการเรียกดูสถานะปัจจุบัน ให้ใช้เอนด์พอยต์ [ดูการตั้งค่าพฤติกรรมการเทรด](/v5/account/get-user-setting-config) และตรวจสอบฟิลด์ `deltaEnable` ในการตอบกลับ

### คำขอ HTTP
<APIEndpoint method="POST" url="/v5/account/set-delta-mode" />

### พารามิเตอร์คำขอ {#request-parameters}
| พารามิเตอร์ | จำเป็น | ประเภท | คำอธิบาย|
|:----- |:-------|:-----|------ |
|deltaEnable |**true** |string |`1`: เปิดใช้งาน; `0`: ปิดใช้งาน|

### พารามิเตอร์การตอบกลับ {#response-parameters}
| พารามิเตอร์ | ประเภท | คำอธิบาย|
|:----- |:-----|----- |
|resultStatus |integer |`success`;`failed`|
