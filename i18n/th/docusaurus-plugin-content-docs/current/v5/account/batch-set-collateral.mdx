### คำขอ HTTP
<APIEndpoint method="POST" url="/v5/account/set-collateral-switch-batch" />

### พารามิเตอร์คำขอ {#request-parameters}
| พารามิเตอร์ | จำเป็น | ประเภท | คำอธิบาย|
|:----- |:-------|:-----|------ |
|request |**true** |array |Object|
|> coin |**true** |string |ชื่อเหรียญ ตัวพิมพ์ใหญ่เท่านั้น <ul><li>คุณสามารถดูเหรียญหลักประกันได้ [ที่นี่](collateral-info)</li><li>ไม่สามารถตั้งค่า USDT, USDC ได้</li></ul>|
|> collateralSwitch |**true** |string |`ON`: เปิดใช้หลักประกัน, `OFF`: ปิดใช้หลักประกัน|

### พารามิเตอร์การตอบกลับ {#response-parameters}
| พารามิเตอร์ | ประเภท | คำอธิบาย|
|:----- |:-----|------ |
|result |Object | |
|> list |array |Object|
|>> coin |string |ชื่อเหรียญ|
|>> collateralSwitch |string |`ON`: เปิดใช้หลักประกัน, `OFF`: ปิดใช้หลักประกัน|
