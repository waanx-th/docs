:::info
* เมื่อ mmp ถูกทริกเกอร์แล้ว คุณสามารถปลดการอายัดบัญชีได้ด้วยเอนด์พอยต์นี้ จากนั้น `qtyLimit`, `deltaLimit` และ `vegaLimit` จะถูกรีเซ็ตเป็น 0
* หากบัญชีไม่ได้ถูกอายัด การรีเซ็ตก็สามารถลบยอดสะสมก่อนหน้าออกได้เช่นกัน กล่าวคือ `qtyLimit`, `deltaLimit` และ `vegaLimit` จะถูกรีเซ็ตเป็น 0
:::

### คำขอ HTTP
<APIEndpoint method="POST" url="/v5/account/mmp-reset" />

### พารามิเตอร์คำขอ {#request-parameters}
| พารามิเตอร์ | จำเป็น | ประเภท | คำอธิบาย|
|:----- |:-------|:-----|------ |
|baseCoin |**true** |string |เหรียญฐาน ตัวพิมพ์ใหญ่เท่านั้น|

### พารามิเตอร์การตอบกลับ {#response-parameters}
ไม่มี
