:::tip คำแนะนำการอัปเกรด
ตรวจสอบสถานะบัญชีปัจจุบันของคุณโดยเรียก[ดูข้อมูลบัญชี](account-info) นี้

* หาก unifiedMarginStatus=5 แสดงว่าเป็น UTA2.0 คุณสามารถเรียกเอนด์พอยต์อัปเกรดด้านล่างเพื่ออัปเกรดเป็น UTA2.0 Pro ได้ ตรวจสอบ
[ดูข้อมูลบัญชี](account-info) อีกครั้งหลังผ่านไปสักระยะ หาก unifiedMarginStatus=6 แสดงว่าบัญชีอัปเกรดเป็น UTA2.0 Pro สำเร็จแล้ว
* เมื่อผู้ใช้เป็นบัญชีหลัก ผู้ใช้ปัจจุบันจะได้รับอนุญาตให้อัปเกรดเป็น UTA PRO หากเป็นผู้ใช้ระดับ VIP หรือ PRO
* เมื่อผู้ใช้เป็นบัญชีย่อย เฉพาะบัญชีแม่ที่มีระดับ VIP หรือ PRO เท่านั้นที่ได้รับอนุญาตให้อัปเกรดเป็น UTA PRO
:::

:::info
โปรดทราบสิ่งต่อไปนี้:
1. โปรดหลีกเลี่ยงการอัปเกรดในช่วงเวลาเหล่านี้:

| | |
|:----- |:-----|
|ทุกชั่วโมง | นาทีที่ 50 ถึงนาทีที่ 5 ของชั่วโมงถัดไป |

2. ห้ามอัปเกรดจาก UTA PUBLIC เป็น UTA PRO ทุกวันในช่วง **07:55 ถึง 08:05 UTC+0**<br/><br/>
3. โปรดตรวจสอบให้แน่ใจว่าไม่มีคำสั่งที่ยังไม่จับคู่ตอนอัปเกรดจาก UTA2.0 เป็น UTA2.0 Pro<br/><br/>
3. ในระหว่างขั้นตอนการอัปเกรดบัญชี ข้อมูลของ **Rest API/Websocket stream** อาจไม่ถูกต้อง เนื่องจากข้อมูลสินทรัพย์ที่เกี่ยวข้อง
กับบัญชีอยู่ในสถานะกำลังประมวลผล ขอแนะนำให้เรียกดูและใช้งานหลังจากการอัปเกรดเสร็จสมบูรณ์แล้ว
:::

### คำขอ HTTP
<APIEndpoint method="POST" url="/v5/account/upgrade-to-uta" />

### พารามิเตอร์คำขอ {#request-parameters}
ไม่มี

### พารามิเตอร์การตอบกลับ {#response-parameters}
| พารามิเตอร์ | ประเภท | คำอธิบาย|
|:----- |:-----|----- |
|unifiedUpdateStatus |string | สถานะการอัปเกรด `FAIL`,`PROCESS`,`SUCCESS` |
|unifiedUpdateMsg |Object |หากเป็น `PROCESS`,`SUCCESS` จะคืนค่า `null` |
|> msg |array |อาร์เรย์ข้อความข้อผิดพลาด มีเฉพาะกรณี `FAIL` เท่านั้น |
