เรียกดูจำนวนที่สามารถโอนได้ของเหรียญที่ระบุในกระเป๋า Unified

:::info
สูตรคำนวณยอดคงเหลือที่ใช้ได้ของสินทรัพย์สำหรับการถอน: 
1. คำนวณย้อนกลับเพื่อหาจำนวนที่ใช้ได้ของสินทรัพย์ = X โดยใช้ `totalAvailableBalance` ใน [ดูยอดคงเหลือในกระเป๋า](wallet-balance#) และอัตราหลักประกันแบบขั้นบันไดของสินทรัพย์นั้น <br/>
2. ยอดคงเหลือที่ใช้ได้ของสินทรัพย์สำหรับการถอน = min(X, ยอดคงเหลือที่ใช้ได้สำหรับการถอนของสินทรัพย์)
- ในโหมด Cross margin: ยอดคงเหลือที่ใช้ได้สำหรับการถอนของสินทรัพย์ = ยอดคงเหลือในกระเป๋าของสินทรัพย์ + min(unrealised pnl,0) + asset reservation - frozen - bonus + orderloss <br/>
- ในโหมด Portfolio margin: ยอดคงเหลือที่ใช้ได้สำหรับการถอนของสินทรัพย์ = ยอดคงเหลือในกระเป๋าของสินทรัพย์ + min(unrealised pnl,0) + asset reservation - frozen  - max(bonus, Pm spot Hedged Balance) + orderloss <br/>
3. ในช่วงที่ตลาดผันผวนรุนแรง อินเทอร์เฟซนี้อาจมีความหน่วงเพิ่มขึ้นหรือการส่งข้อมูลล่าช้าชั่วคราว
:::

### คำขอ HTTP
<APIEndpoint method="GET" url="/v5/account/withdrawal" />

### พารามิเตอร์คำขอ {#request-parameters}
| พารามิเตอร์ | จำเป็น | ประเภท | คำอธิบาย|
|:----- |:-------|:-----|------ |
|coinName |**true** |string |ชื่อเหรียญ ตัวพิมพ์ใหญ่เท่านั้น รองรับได้ถึง 20 เหรียญต่อคำขอ คั่นด้วยเครื่องหมายจุลภาค `BTC,USDC,USDT,SOL`|

### พารามิเตอร์การตอบกลับ {#response-parameters}
| พารามิเตอร์ | ประเภท | คำอธิบาย|
|:----- |:-----|----- |
|availableWithdrawal |string |จำนวนที่โอนได้ของเหรียญตัวแรกในคำขอ|
|availableWithdrawalMap |Object |แมปจำนวนที่โอนได้ของแต่ละเหรียญที่ร้องขอ ในแมปนี้ คีย์คือเหรียญที่ร้องขอ และค่าคือจำนวนที่สอดคล้องกัน(string)<br/>เช่น "availableWithdrawalMap":&#123;"BTC":"4.54549050","SOL":"33.16713007","XRP":"10805.54548970","ETH":"17.76451865"&#125;|
