คุณสามารถดึงการตั้งค่าว่าระบบจะทำงานอย่างไรเมื่อราคาคำสั่งแบบจำกัดราคาของคุณเกินราคาเสนอซื้อสูงสุดหรือราคาเสนอขายต่ำสุด การตอบกลับยังระบุด้วยว่า [โหมด Delta Neutral](/v5/account/set-delta-mode) เปิดใช้อยู่หรือไม่

---

โดยที่ x% คือ [priceLimitRatioX](/v5/market/instrument) และ y% คือ [priceLimitRatioY](/v5/market/instrument):

* **ราคาซื้อสูงสุด**: *Min[Max(Index Price, Index Price × (1 + x%) + 2-Minute Average Premium), Index Price × (1 + y%)]*
* **ราคาขายต่ำสุด**: *Max[Min(Index Price, Index Price × (1 – x%) + 2-Minute Average Premium), Index Price × (1 – y%)]*

:::info การตั้งค่าเริ่มต้น
**lpaSpot = false.** หากราคาคำสั่งซื้อขายเกินขีดจำกัด ระบบจะปฏิเสธคำขอ
:::

### คำขอ HTTP
<APIEndpoint method="GET" url="/v5/account/user-setting-config" />

### พารามิเตอร์คำขอ {#request-parameters}
ไม่มี

### พารามิเตอร์การตอบกลับ {#response-parameters}
| พารามิเตอร์ | ประเภท | คำอธิบาย|
|:----- |:-----|----- |
|result |array |Object |
|> lpaSpot |boolean |<ul><li>`true`: หากราคาคำสั่งซื้อขายเกินขีดจำกัด ระบบจะปรับราคาไปยังราคาที่อนุญาตใกล้ที่สุดโดยอัตโนมัติ</li><li>`false`: หากราคาคำสั่งซื้อขายเกินขีดจำกัด ระบบจะปฏิเสธคำขอ</li></ul>|
|> deltaEnable |boolean |[โหมด Delta Neutral](/v5/account/set-delta-mode) เปิดใช้อยู่หรือไม่ `true`: เปิดใช้; `false`: ปิดใช้|
|> smsef |boolean |เปิดใช้การหักค่าธรรมเนียมด้วย MNT สำหรับสปอตหรือไม่ `true`: เปิดใช้; `false`: ปิดใช้|
|> smpType |integer |การตั้งค่าประเภท SMP (Self-Match Prevention) ของผู้ใช้ `0`: ค่าเริ่มต้น ไม่ทริกเกอร์การป้องกันการจับคู่กับตนเอง; `1`: ยกเลิกคำสั่ง Taker เมื่อตรวจพบการจับคู่กับตนเอง; `2`: ยกเลิกคำสั่ง Maker เมื่อตรวจพบการจับคู่กับตนเอง; `3`: ยกเลิกทั้งคำสั่ง Maker และ Taker เมื่อตรวจพบการจับคู่กับตนเอง|
