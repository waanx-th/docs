เรียกดู SMP group ID ของการป้องกันการจับคู่กับตัวเอง

### คำขอ HTTP
<APIEndpoint method="GET" url="/v5/account/smp-group" />

### พารามิเตอร์คำขอ {#request-parameters}
ไม่มี

### พารามิเตอร์การตอบกลับ {#response-parameters}
| พารามิเตอร์ | ประเภท | คำอธิบาย|
|:----- |:-----|----- |
|smpGroup |integer |SMP group ID หาก UID นั้นไม่ได้อยู่ในกลุ่มใด ค่าเริ่มต้นจะเป็น `0` |
