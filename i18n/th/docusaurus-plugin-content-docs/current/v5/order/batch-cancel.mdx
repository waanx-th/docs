เอนด์พอยต์นี้ช่วยให้คุณยกเลิกคำสั่งที่ยังไม่จับคู่ได้มากกว่าหนึ่งคำสั่งในคำขอเดียว

:::info สำคัญ
- คุณต้องระบุ `orderId` หรือ `orderLinkId`
- หาก `orderId` และ `orderLinkId` ไม่ตรงกัน ระบบจะประมวลผล `orderId` ก่อน
- คุณสามารถยกเลิกคำสั่งซื้อขายที่**ยังไม่จับคู่**หรือ**จับคู่สำเร็จบางส่วน**ได้
- ยกเลิกได้สูงสุด 10 คำสั่ง (สปอต) ต่อหนึ่งคำขอ
:::

### คำขอ HTTP
<APIEndpoint method="POST" url="/v5/order/cancel-batch" />

### พารามิเตอร์คำขอ {#request-parameters}
| พารามิเตอร์ | จำเป็น | ประเภท | คำอธิบาย|
|:----- |:-------|:-----|------ |
|[category](../enum#category) |**true** |string |ประเภทผลิตภัณฑ์ `spot`|
|request |**true** |array |อ็อบเจกต์ |
|> symbol |**true** |string |ชื่อสัญลักษณ์คู่เทรด เช่น `BTCUSDT` ตัวพิมพ์ใหญ่เท่านั้น  |
|> orderId |false |string |รหัสคำสั่งซื้อขาย ต้องระบุ `orderId` หรือ `orderLinkId` อย่างใดอย่างหนึ่ง |
|> orderLinkId |false |string |รหัสคำสั่งซื้อขายที่ผู้ใช้กำหนดเอง ต้องระบุ `orderId` หรือ `orderLinkId` อย่างใดอย่างหนึ่ง |

### พารามิเตอร์การตอบกลับ {#response-parameters}
| พารามิเตอร์ | ประเภท | คำอธิบาย|
|:----- |:-----|----- |
|result |Object | |
|> list |array |อ็อบเจกต์ |
|>> category |string |ประเภทผลิตภัณฑ์ |
|>> symbol |string |ชื่อสัญลักษณ์คู่เทรด |
|>> orderId |string |รหัสคำสั่งซื้อขาย |
|>> orderLinkId |string |รหัสคำสั่งซื้อขายที่ผู้ใช้กำหนดเอง |
|retExtInfo |Object | |
|> list |array |อ็อบเจกต์ |
|>> code |number |รหัสสำเร็จ/ข้อผิดพลาด |
|>> msg |string |ข้อความสำเร็จ/ข้อผิดพลาด |

:::info
การตอบรับ (ack) ของคำขอยกเลิกคำสั่งซื้อขายหมายความเพียงว่าคำขอถูกรับเข้าระบบสำเร็จแล้ว คำขอนี้เป็นแบบอะซิงโครนัส ดังนั้นโปรดใช้ WebSocket เพื่อยืนยันสถานะของคำสั่งซื้อขาย
:::
