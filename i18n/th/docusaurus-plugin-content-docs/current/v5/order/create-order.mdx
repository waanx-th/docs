เอกสารฉบับร่างนี้ครอบคลุมคำสั่งซื้อขายสปอต การเทรดสปอตมาร์จิ้นไม่อยู่ในขอบเขตผลิตภัณฑ์ WaanX ระยะที่ 1

:::info
- **ประเภทคำสั่งซื้อขายที่รองรับ (`orderType`):**<br/>
คำสั่งแบบจำกัดราคา: `orderType`=_Limit_ ต้องระบุจำนวนและราคาคำสั่งซื้อขาย<br/>
<a href="https://support.waanx.com/en/support/home">คำสั่งแบบราคาตลาด</a>: <code>orderType</code>=<i>Market</i> จะจับคู่ที่ราคาที่ดีที่สุดในตลาดของ WaanX จนกระทั่งจับคู่สำเร็จครบจำนวน เมื่อเลือกคำสั่งแบบราคาตลาด ฟิลด์ "price" สามารถเว้นว่างได้ ในระบบการเทรด เพื่อคุ้มครองผู้เทรดจากสลิปเพจที่รุนแรงของคำสั่งแบบราคาตลาด เอนจินการเทรดของ WaanX จะแปลงคำสั่งแบบราคาตลาดให้เป็นคำสั่งแบบจำกัดราคาชนิด IOC เพื่อนำไปจับคู่ หากไม่มีรายการในสมุดคำสั่งซื้อขายอยู่ภายในขอบเขตสลิปเพจของราคา คำสั่งดังกล่าวจะไม่ถูกจับคู่ และหากสภาพคล่องไม่เพียงพอ คำสั่งดังกล่าวจะถูกยกเลิก ค่าขอบเขตสลิปเพจหมายถึงเปอร์เซ็นต์ที่ราคาคำสั่งซื้อขายเบี่ยงเบนจากราคาซื้อขายล่าสุด ดูรายละเอียดเพิ่มเติมได้ที่: <a href="https://waanx.com/en/gb/announcements">การปรับกลไกจำกัดราคาการเทรดของ WaanX</a>

- **กลยุทธ์ timeInForce ที่รองรับ:**<br/>
`GTC`<br/>
`IOC`<br/>
`FOK`<br/>
`PostOnly`: หากคำสั่งซื้อขายจะถูกจับคู่ทันทีเมื่อส่งเข้าระบบ คำสั่งนั้นจะถูก**ยกเลิก** วัตถุประสงค์คือเพื่อคุ้มครองคำสั่งของคุณในระหว่างขั้นตอนการส่งคำสั่ง หากระบบจับคู่ไม่สามารถนำคำสั่งเข้าสู่สมุดคำสั่งซื้อขายได้เนื่องจากราคาในตลาดเปลี่ยนแปลง คำสั่งนั้นจะถูกยกเลิก<br/>
`RPI`: คำสั่งซื้อขายแบบปรับปรุงราคาสำหรับนักลงทุนรายย่อย (Retail Price Improvement) ผู้ดูแลสภาพคล่องที่ได้รับกำหนดสิทธิ์เท่านั้นที่สามารถส่งคำสั่งประเภทนี้ได้ โดยคำสั่งนี้มีคุณสมบัติเป็นคำสั่งแบบ post only และจับคู่ได้เฉพาะกับคำสั่งที่มาจากเว็บหรือแอปพลิเคชันเท่านั้น

- **วิธีสร้างคำสั่งแบบมีเงื่อนไข:**<br/>
เมื่อส่งคำสั่งซื้อขาย การตั้งค่า `triggerPrice` จะสร้างคำสั่งแบบมีเงื่อนไข ประเภทคำสั่งที่ WaanX รองรับยังต้องยืนยันกับทีม API

- **<a href="https://support.waanx.com/en/support/home">ทำกำไร / หยุดขาดทุน</a>**: คุณสามารถตั้งค่า TP/SL ขณะสร้างคำสั่งซื้อขายได้

- **จำนวนคำสั่งซื้อขาย**: จำนวนที่คุณต้องการซื้อ/ขาย สำหรับจำนวนคำสั่งซื้อขาย ปัจจุบัน WaanX รองรับเฉพาะค่าที่เป็นจำนวนบวกเท่านั้น

- **ราคาคำสั่งซื้อขาย**: เมื่อสร้างคำสั่งแบบจำกัดราคา พารามิเตอร์นี้**จำเป็น**
สำหรับหน่วยขั้นต่ำของการเปลี่ยนแปลงราคา โปรดดูฟิลด์ `priceFilter` > `tickSize` ในเอนด์พอยต์ [instruments-info](../market/instrument#)

- **orderLinkId**: คุณสามารถกำหนดรหัสของคำสั่งที่ยังไม่จับคู่ได้เอง ระบบจะเชื่อมโยงรหัสนี้เข้ากับรหัสคำสั่งซื้อขายในระบบ เมื่อ
คำสั่งที่ยังไม่จับคู่ถูกสร้างสำเร็จ ระบบจะส่งรหัสคำสั่งซื้อขายที่ไม่ซ้ำกันในระบบกลับไปให้คุณ จากนั้นคุณสามารถใช้รหัสคำสั่งซื้อขาย
นี้เพื่อยกเลิกคำสั่งที่ยังไม่จับคู่ได้ และหากมีการส่งทั้ง orderId และ orderLinkId เข้ามาในพารามิเตอร์ WaanX จะให้ลำดับความสำคัญกับ orderId ในการประมวลผลคำสั่งที่เกี่ยวข้อง ทั้งนี้ รหัสคำสั่งซื้อขายที่คุณกำหนดเองต้องมีความยาวไม่เกิน 36 อักขระ และต้อง**ไม่ซ้ำกัน**

- **ขีดจำกัดจำนวนคำสั่งที่ยังไม่จับคู่:**<br/>
**สปอต:** รวมทั้งหมด 500 คำสั่ง โดยแต่ละบัญชีต่อหนึ่งสัญลักษณ์คู่เทรดสามารถมีคำสั่ง TP/SL ที่ยังไม่จับคู่ได้สูงสุด 30 คำสั่ง และคำสั่งแบบมีเงื่อนไขที่ยังไม่จับคู่ได้สูงสุด 30 คำสั่ง

- **การจำกัดอัตราการเรียก:**<br/>
โปรดดู[ตารางการจำกัดอัตราการเรียก](../rate-limit#trade) หากคุณต้องการเพิ่มอัตราการเรียก โปรดติดต่อผู้จัดการลูกค้าของคุณ หรือยื่นคำขอผ่าน<a href="https://waanx.com">ที่นี่</a>

- **ประกาศเกี่ยวกับข้อจำกัดในการควบคุมความเสี่ยง:**<br/>
WaanX จะตรวจสอบและติดตามคำขอ API ของคุณ เมื่อจำนวนคำสั่งซื้อขายรวมของผู้ใช้รายเดียว (นับรวมจำนวนคำสั่งซื้อขายของบัญชีหลักและบัญชีย่อยทั้งหมด) ภายในหนึ่งวัน (UTC 0 - UTC 24) เกินขีดจำกัดที่กำหนด แพลตฟอร์มขอสงวนสิทธิ์ในการแจ้งเตือน ตักเตือน และกำหนดข้อจำกัดที่จำเป็น
ลูกค้าที่ใช้ API ถือว่ายอมรับข้อกำหนดเหล่านี้โดยปริยาย และมีหน้าที่ให้ความร่วมมือในการปรับเปลี่ยน
:::

| พารามิเตอร์ | จำเป็น | ประเภท | คำอธิบาย|
|:----- |:-------|:-----|------ |
|category |**true** |string |ประเภทผลิตภัณฑ์ `spot`|
|symbol |**true** |string |ชื่อสัญลักษณ์คู่เทรด เช่น `BTCUSDT` ตัวพิมพ์ใหญ่เท่านั้น|
|isLeverage |false |integer |พารามิเตอร์จาก API V5 เดิม ใช้ `0` สำหรับสปอต ส่วน `1` เปิดใช้สปอตมาร์จิ้นซึ่งไม่อยู่ในขอบเขตผลิตภัณฑ์ WaanX ระยะที่ 1|
|side |**true** |string |`Buy`, `Sell`|
|[orderType](../enum#ordertype) |**true** |string |`Market`, `Limit`|
|qty |**true** |string |จำนวนคำสั่งซื้อขาย <ul><li>สปอต: คำสั่งซื้อแบบราคาตลาดจะคิดตามมูลค่าเป็นค่าเริ่มต้น คุณสามารถตั้งค่าฟิลด์ `marketUnit` เพื่อเลือกว่าจะสั่งตามมูลค่าหรือตามจำนวนสำหรับคำสั่งแบบราคาตลาด</li></ul>|
|marketUnit |false |string |เลือกหน่วยของ `qty` เมื่อสร้างคำสั่ง**แบบราคาตลาดในตลาดสปอต**<ul><li>`baseCoin`: ตัวอย่างเช่น ซื้อ BTCUSDT หน่วยของ "qty" จะเป็น BTC</li><li>`quoteCoin`: ตัวอย่างเช่น ขาย BTCUSDT หน่วยของ "qty" จะเป็น USDT</li></ul>|
|rpiTakerAccess |false |boolean |`true`: คำสั่งของคุณจะมีสิทธิ์จับคู่กับราคาเสนอแบบ RPI, `false`: ไม่มีสิทธิ์ โปรดอ่าน[คุณสมบัติของ RPI taker](https://waanx.com/en/gb/announcements)|
|slippageToleranceType |false |string |ประเภทค่าความคลาดเคลื่อนของสลิปเพจสำหรับ**คำสั่งแบบราคาตลาด**, `TickSize`, `Percent`<ul><li>ไม่รองรับคำสั่งทำกำไร คำสั่งหยุดขาดทุน และคำสั่งแบบมีเงื่อนไข</li><li><b>TickSize</b>: <br/>ราคาสูงสุดของคำสั่งซื้อ = ask1 + <code>slippageTolerance</code> x tickSize; <br/>ราคาต่ำสุดของคำสั่งขาย = bid1 - <code>slippageTolerance</code> x tickSize</li><li><b>Percent</b>: <br/>ราคาสูงสุดของคำสั่งซื้อ = ask1 x (1 + <code>slippageTolerance</code> x 0.01); <br/>ราคาต่ำสุดของคำสั่งขาย = bid1 x (1 - `slippageTolerance` x 0.01)</li><li>ดูข้อมูลเพิ่มเติมเกี่ยวกับค่าความคลาดเคลื่อนของสลิปเพจได้ที่[ศูนย์ช่วยเหลือ](https://support.waanx.com/en/support/home)</li></ul>|
|slippageTolerance |false |string |ค่าความคลาดเคลื่อนของสลิปเพจ <ul><li>`TickSize`: ช่วงค่าคือ [1, 10000] จำนวนเต็มเท่านั้น</li><li>`Percent`: ช่วงค่าคือ [0.01, 10] ทศนิยมไม่เกิน 2 ตำแหน่ง</li></ul>|
|price |false |string |ราคาคำสั่งซื้อขาย <ul><li>คำสั่งแบบราคาตลาดจะไม่สนใจฟิลด์นี้</li><li>โปรดตรวจสอบราคาต่ำสุดและความละเอียดของราคาจากเอนด์พอยต์ [instrument info](../market/instrument#response-parameters)</li></ul> |
|orderFilter |false |string |หากไม่ส่งค่ามา จะใช้ `Order` เป็นค่าเริ่มต้น <ul><li>`Order`</li><li>`tpslOrder`: คำสั่ง TP/SL ของสปอต สินทรัพย์จะถูกกันไว้ตั้งแต่ก่อนที่คำสั่งจะถูกทริกเกอร์</li><li>`StopOrder`: คำสั่งแบบมีเงื่อนไขของสปอต สินทรัพย์จะยังไม่ถูกกันไว้จนกว่าราคาของสินทรัพย์อ้างอิงจะถึงราคาทริกเกอร์ และสินทรัพย์ที่จำเป็นจะถูกกันไว้หลังจากคำสั่งแบบมีเงื่อนไขถูกทริกเกอร์แล้ว</li></ul>ใช้ได้กับ `spot` **เท่านั้น**|
|triggerPrice |false |string |<ul><li>สำหรับสปอต นี่คือราคาทริกเกอร์ของคำสั่ง TP/SL และคำสั่งแบบมีเงื่อนไข</li></ul>|
|[timeInForce](../enum#timeinforce) |false |string |<a href="https://support.waanx.com/en/support/home">ระยะเวลามีผลของคำสั่ง</a> <ul><li>คำสั่งแบบราคาตลาดจะใช้ `IOC` เสมอ</li><li>หากไม่ส่งค่ามา จะใช้ `GTC` เป็นค่าเริ่มต้น</li> </ul>|
|orderLinkId |false |string |รหัสคำสั่งซื้อขายที่ผู้ใช้กำหนดเอง ความยาวไม่เกิน 36 อักขระ รองรับการผสมกันของตัวเลข ตัวอักษร (ทั้งพิมพ์ใหญ่และพิมพ์เล็ก) เครื่องหมายขีดกลาง และเครื่องหมายขีดล่าง<br/>_สปอต: กฎของ orderLinkId:_ <ul><li>เป็นพารามิเตอร์ที่ไม่จำเป็น</li><li>ต้องไม่ซ้ำกันเสมอ</li></ul>_ออปชัน: กฎของ orderLinkId:_ <ul><li>เป็นพารามิเตอร์ที่**จำเป็น**</li><li>ต้องไม่ซ้ำกันเสมอ</li></ul>|
|takeProfit |false |string |ราคาทำกำไร<ul><li>คำสั่งแบบจำกัดราคาในตลาดสปอตรองรับการตั้งค่าทำกำไร หยุดขาดทุน หรือทำกำไรแบบจำกัดราคาและหยุดขาดทุนแบบจำกัดราคา เมื่อสร้างคำสั่งซื้อขาย</li></ul>|
|stopLoss |false |string |ราคาหยุดขาดทุน <ul><li>คำสั่งแบบจำกัดราคาในตลาดสปอตรองรับการตั้งค่าทำกำไร หยุดขาดทุน หรือทำกำไรแบบจำกัดราคาและหยุดขาดทุนแบบจำกัดราคา เมื่อสร้างคำสั่งซื้อขาย</li></ul>|
|[smpType](../enum#smptype) |false |string |ประเภทการดำเนินการของ Smp [SMP คืออะไร?](../smp)|
|tpLimitPrice |false |string |ราคาของคำสั่งแบบจำกัดราคาเมื่อราคาทำกำไรถูกทริกเกอร์ <ul><li>สปอต: จำเป็นเมื่อคำสั่งมีการตั้งค่า `takeProfit` และ "tpOrderType"=`Limit`</li></ul>|
|slLimitPrice |false |string |ราคาของคำสั่งแบบจำกัดราคาเมื่อราคาหยุดขาดทุนถูกทริกเกอร์<ul><li>สปอต: จำเป็นเมื่อคำสั่งมีการตั้งค่า `stopLoss` และ "slOrderType"=`Limit`</li></ul>|
|tpOrderType |false |string |ประเภทคำสั่งซื้อขายเมื่อการทำกำไรถูกทริกเกอร์ <ul><li>สปอต: <br/>`Market`: เมื่อคุณตั้งค่า "takeProfit", <br/>`Limit`: เมื่อคุณตั้งค่า "takeProfit" และ "tpLimitPrice" </li></ul>|
|slOrderType |false |string |ประเภทคำสั่งซื้อขายเมื่อการหยุดขาดทุนถูกทริกเกอร์ <ul><li>สปอต: <br/>`Market`: เมื่อคุณตั้งค่า "stopLoss", <br/>`Limit`: เมื่อคุณตั้งค่า "stopLoss" และ "slLimitPrice" </li></ul>|

### พารามิเตอร์การตอบกลับ {#response-parameters}
| พารามิเตอร์ | ประเภท | คำอธิบาย|
|:----- |:-----|----- |
|orderId |string |รหัสคำสั่งซื้อขาย |
|orderLinkId |string |รหัสคำสั่งซื้อขายที่ผู้ใช้กำหนดเอง |

:::info
การตอบรับ (ack) ของคำขอสร้างคำสั่งซื้อขายหมายความเพียงว่าคำขอถูกรับเข้าระบบสำเร็จแล้ว คำขอนี้เป็นแบบอะซิงโครนัส ดังนั้นโปรดใช้ WebSocket เพื่อยืนยันสถานะของคำสั่งซื้อขาย
:::
