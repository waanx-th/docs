## ภาพรวม
เอกสารฉบับร่างนี้กำลังปรับให้สอดคล้องกับขอบเขตผลิตภัณฑ์ของ WaanX ประเทศไทย ระยะที่ 1 มุ่งเน้น
การดูแลสินทรัพย์ การฝากและถอนเงินสกุลปกติ การซื้อขายสปอตคู่ THB และ USDT รวมถึงการแปลงสินทรัพย์
แบบสปอต (รวมยอดคงเหลือจำนวนเล็กน้อย) ขอบเขตผลิตภัณฑ์เพียงอย่างเดียวไม่ได้ยืนยันว่า API
แต่ละรายการพร้อมใช้งาน

## พาธของ API
พาธ API V5 แบ่งการดำเนินการออกเป็นข้อมูลตลาด คำสั่งซื้อขาย บัญชี และสินทรัพย์

> &#123;host&#125;/&#123;version&#125;/&#123;product&#125;/&#123;module&#125;<br/>
ตัวอย่าง: api.waanx.com/v5/market/recent-trade

|ส่วนของที่อยู่  | คำอธิบาย |
|:----- |-------|
|v5/market/|กราฟแท่งเทียน สมุดคำสั่งซื้อขาย ทิกเกอร์ ข้อมูลธุรกรรมของแพลตฟอร์ม กฎทางการเงินของสินทรัพย์อ้างอิง กฎการควบคุมความเสี่ยง|
|v5/order/|การจัดการคำสั่งซื้อขาย|
|v5/account/|ข้อมูลบัญชีและอัตราค่าธรรมเนียม|
|v5/asset/|การดำเนินการข้ามหลายบัญชี – การจัดการสินทรัพย์ การจัดการเงินทุน ฯลฯ|
