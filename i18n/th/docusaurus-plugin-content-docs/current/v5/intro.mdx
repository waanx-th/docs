## การอัปเกรดที่สำคัญ
### การรวมกลุ่มผลิตภัณฑ์ให้เป็นมาตรฐานเดียวกัน
V5 รวม API ของผลิตภัณฑ์การเทรดต่าง ๆ ให้เป็นหนึ่งเดียว ทำให้ผู้ใช้สามารถเทรดสปอต
ได้ด้วย API ชุดเดียว โดยแยกแยะรายการผ่านพารามิเตอร์คำสั่งซื้อขายที่แตกต่างกัน
ดังนั้นจึงไม่จำเป็นต้องสลับไปมาระหว่างอินเทอร์เฟซหลายชุดเมื่อสร้างผลิตภัณฑ์ที่แตกต่างกัน ไม่ว่าจะเป็น
งานอย่างการจัดการคำสั่งซื้อขายหรือการค้นหาข้อมูลกระเป๋าเงิน เพราะสามารถใช้ API ชุดเดียวกันในการส่งคำขอและรับผลลัพธ์ได้

พจนานุกรมส่วนกลางใน V5 ถูกกำหนดไว้อย่างไม่ซ้ำกัน เพื่อหลีกเลี่ยงกรณีที่ใช้คำต่างกันสำหรับวัตถุประสงค์เดียวกัน
หรือกรณีที่คำเดียวมีความหมายอ้างอิงหลายอย่าง ซึ่งช่วยให้ผู้ใช้ตรวจสอบและแก้ไขปัญหาได้ง่ายขึ้น

ตัวอย่างเช่น เมื่อสร้างคำสั่งซื้อขายด้วย `POST /v5/order/create` ผู้ใช้สามารถระบุ `category=spot` ได้

### เพิ่มประสิทธิภาพการใช้เงินทุน
V5 ให้ผู้ใช้สามารถอัปเกรดบัญชีเป็นบัญชีแบบรวมได้ ซึ่งเปิดให้ใช้เงินทุนร่วมกันและใช้ข้ามกันได้
ภายในบัญชีเดียว จึงเพิ่มประสิทธิภาพการใช้เงินทุนได้มากยิ่งขึ้น

### การกู้ยืมในบัญชีแบบรวม
API V5 รองรับการกู้ยืมภายใต้โหมดบัญชีแบบรวม ผู้ใช้สามารถวางสินทรัพย์หลายรายการเป็นหลักประกันเพื่อรับมาร์จิ้น
สำหรับการเทรดมาร์จิ้นแบบสปอตได้

### มาตรฐานการตั้งชื่ออินเทอร์เฟซ API
API V5 กำหนดพาธได้ชัดเจนยิ่งขึ้น เพื่อความเข้าใจที่ดีขึ้นและลดความกำกวม เวอร์ชันใหม่แบ่งพาธของ API
ออกเป็นโมดูลข้อมูลตลาด การจัดการคำสั่งซื้อขาย การจัดการบัญชี การจัดการสินทรัพย์ และโมดูลอื่น ๆ

> {host}/{version}/{product}/{module}<br/>
ตัวอย่าง: api.waanx.com/v5/market/recent-trade

|ส่วนของที่อยู่  | คำอธิบาย |
|:----- |-------|
|v5/market/|กราฟแท่งเทียน สมุดคำสั่งซื้อขาย ทิกเกอร์ ข้อมูลธุรกรรมของแพลตฟอร์ม กฎทางการเงินของสินทรัพย์อ้างอิง กฎการควบคุมความเสี่ยง|
|v5/order/|การจัดการคำสั่งซื้อขาย|
|v5/account/|การดำเนินการภายในบัญชีเดียวเท่านั้น – บัญชีเงินทุนแบบรวม อัตราต่าง ๆ ฯลฯ|
|v5/asset/|การดำเนินการข้ามหลายบัญชี – การจัดการสินทรัพย์ การจัดการเงินทุน ฯลฯ|

### การปรับปรุงความอ่านง่ายของเอกสาร API
เอกสาร API ได้รับการปรับปรุงและตรวจทานเพื่อให้ชัดเจนขึ้นและลดความสับสน ส่วนใดของ
เอกสารเวอร์ชันก่อนที่ไม่ชัดเจนได้รับการแก้ไขเพื่อให้คำอธิบายที่ดีขึ้น
