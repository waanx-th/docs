### คำขอ HTTP
<APIEndpoint method="GET" url="/v5/market/time" />

### พารามิเตอร์คำขอ {#request-parameters}
ไม่มี

### พารามิเตอร์การตอบกลับ {#response-parameters}
| พารามิเตอร์ | ประเภท | คำอธิบาย|
|:----- |:-----|----- |
| timeSecond | string | ประทับเวลาเซิร์ฟเวอร์ WaanX (sec)  |
| timeNano | string | ประทับเวลาเซิร์ฟเวอร์ WaanX (nano)  |
