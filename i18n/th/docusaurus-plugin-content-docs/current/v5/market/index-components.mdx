### คำขอ HTTP
<APIEndpoint method="GET" url="/v5/market/index-price-components" />

### พารามิเตอร์คำขอ {#request-parameters}
| พารามิเตอร์ | จำเป็น | ประเภท | คำอธิบาย|
|:----- |:-------|:-----|------|
|indexName |**true** |string |ชื่อดัชนี เช่น `BTCUSDT`|

### พารามิเตอร์การตอบกลับ {#response-parameters}
| พารามิเตอร์ | ประเภท | คำอธิบาย|
|:----- |:-----|----- |
| indexName| string | ชื่อของดัชนี (เช่น BTCUSDT)|
| lastPrice| string | ราคาล่าสุดของดัชนี|
| updateTime| string | ประทับเวลาของการอัปเดตครั้งล่าสุด หน่วยมิลลิวินาที |
| components| array| รายการองค์ประกอบที่ใช้คำนวณราคาดัชนี |
|> exchange | string | ชื่อของกระดานเทรด|
|> spotPair | string | คู่เทรดสปอตบนกระดานเทรดนั้น (เช่น BTCUSDT) |
|> equivalentPrice| string | ราคาเทียบเท่า |
|> multiplier | string | ตัวคูณที่ใช้กับราคาขององค์ประกอบ|
|> price| string | ราคาที่เกิดขึ้นจริง |
|> weight | string | น้ำหนักในการคำนวณดัชนี |
