:::info
คีย์ API ต้องมีสิทธิ์ "Earn"
:::

:::note
สำหรับ Flexible Saving การตอบกลับจะรวมโพซิชันที่ไถ่ถอนครบทั้งจำนวนแล้วด้วย
สำหรับ Onchain การตอบกลับจะมีเฉพาะโพซิชันที่ยังทำงานอยู่เท่านั้น
:::

### คำขอ HTTP
<APIEndpoint method="GET" url="/v5/earn/position" />

### พารามิเตอร์คำขอ {#request-parameters}
| พารามิเตอร์ | จำเป็น | ประเภท | คำอธิบาย|
|:----- |:-------|:-----|------ |
|category|**true**|string|`FlexibleSaving`,`OnChain`|
|productId|false|string|รหัสผลิตภัณฑ์|
|coin|false|string|ชื่อเหรียญ|

### พารามิเตอร์การตอบกลับ {#response-parameters}
| พารามิเตอร์ | ประเภท | คำอธิบาย|
|:----- |:-----|----- |
|list|array|Object|
|> coin|string |ชื่อเหรียญ |
|> productId|string |รหัสผลิตภัณฑ์|
|> amount|string |จำนวนที่สเตคไว้ทั้งหมด|
|> totalPnl|string |ส่งกลับกำไรของโพซิชันปัจจุบัน มีค่าเฉพาะในโหมด Onchain non-LST เท่านั้น|
|> claimableYield|string |ผลตอบแทนจะสะสมเป็นรายชั่วโมงและจ่ายทุกวันเวลา 00:30 UTC หากคุณยกเลิกการสเตคสินทรัพย์ก่อนการจ่ายผลตอบแทน ผลตอบแทนที่ยังไม่ได้จ่ายจะถูกโอนเข้าบัญชีของคุณพร้อมกับเงินต้น ผลิตภัณฑ์ Onchain จะไม่ส่งค่ากลับมา|
|> id|string |รหัสโพซิชัน ใช้กับ Onchain เท่านั้น|
|> status|string |`Processing`,`Active` ใช้กับ Onchain เท่านั้น|
|> orderId|string |รหัสคำสั่งซื้อขาย ใช้กับ Onchain เท่านั้น|
|> estimateRedeemTime|string |เวลาไถ่ถอนโดยประมาณ หน่วยมิลลิวินาที ใช้กับ Onchain เท่านั้น|
|> estimateStakeTime|string |เวลาสเตคโดยประมาณ หน่วยมิลลิวินาที ใช้กับ Onchain เท่านั้น|
|> estimateInterestCalculationTime|string |เวลาเริ่มคิดดอกเบี้ยโดยประมาณ หน่วยมิลลิวินาที ใช้กับ Onchain เท่านั้น |
|> settlementTime|string |เวลาชำระราคา หน่วยมิลลิวินาที มีค่าเฉพาะผลิตภัณฑ์ Onchain แบบ `Fixed` เท่านั้น|
|> autoReinvest|string |สถานะการลงทุนต่อโดยอัตโนมัติ `Enable`: เปิดใช้งาน, `Disable`: ปิดใช้งาน ดู[แก้ไขโพซิชัน](modify-position.mdx)|
|> availableAmount|string |จำนวนที่ไถ่ถอนได้|
|> freezeDetails|array |รายการรายละเอียดการอายัด|
|>> amount|string |จำนวนที่ถูกอายัด|
|>> description|string |เหตุผลของการอายัด|
