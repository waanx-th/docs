### คำขอ HTTP
<APIEndpoint method="GET" url="/v5/earn/order" />

### พารามิเตอร์คำขอ {#request-parameters}
| พารามิเตอร์ | จำเป็น | ประเภท | คำอธิบาย|
|:----- |:-------|:-----|------ |
|category|**true**|string|`FlexibleSaving`,`OnChain` <br/>**หมายเหตุ**: ปัจจุบันรองรับเฉพาะ flexible savings และ OnChain เท่านั้น|
|orderId|false|string|รหัสคำสั่งซื้อขาย  <ul><li>สำหรับ category = `OnChain` ต้องระบุ orderId หรือ orderLinkId อย่างใดอย่างหนึ่งเป็น**จำเป็น**</li><li>หากส่งมาทั้งสองค่า โปรดตรวจสอบว่าตรงกัน มิฉะนั้นจะได้ผลลัพธ์ว่าง</li></ul>|
|orderLinkId|false|string|รหัสอ้างอิงคำสั่งซื้อขาย<br/>**หมายเหตุ**: หากค้นหาด้วย orderLinkId เพียงอย่างเดียวและรหัสอ้างอิงคำสั่งซื้อขายนั้นเคยถูกใช้ซ้ำ ระบบจะส่งรายการล่าสุดกลับมาเสมอ|
| productId   | false    | string    | รหัสผลิตภัณฑ์                                                                                                                      |
| startTime   | false    | integer  | ประทับเวลาเริ่มต้น (มิลลิวินาที)<ul><li> 1. หากไม่ได้ระบุทั้งสองค่า ค่าเริ่มต้นคือส่งข้อมูล 7 วันล่าสุดกลับมา</li><li>2. หากระบุทั้งสองค่า ผลต่างระหว่าง endTime และ startTime ต้องน้อยกว่าหรือเท่ากับ 7 วัน </li></ul>                                                                                          |
| endTime     | false    | integer  | ประทับเวลาสิ้นสุด (มิลลิวินาที)                                                                                                              |
| limit       | false    | integer  | จำนวนข้อมูลสูงสุดต่อหน้า ช่วงค่า: [1, 100] ค่าเริ่มต้น: 50                                                                            |
| cursor      | false    | string  | เคอร์เซอร์ ใช้ `nextPageCursor` ที่ส่งกลับมาเพื่อค้นหาข้อมูลหน้าถัดไป                                                       |


### พารามิเตอร์การตอบกลับ {#response-parameters}
| พารามิเตอร์ | ประเภท | คำอธิบาย|
|:----- |:-----|----- |
|nextPageCursor |string |ดูพารามิเตอร์คำขอ `cursor` |
|list|array|Object|
|> coin|string |ชื่อเหรียญ |
|> orderValue|string |จำนวน|
|> orderType|string |`Redeem`, `Stake`|
|> orderId|string |รหัสคำสั่งซื้อขาย|
|> orderLinkId|string |รหัสอ้างอิงคำสั่งซื้อขาย|
|> status|string |สถานะคำสั่ง `Success`, `Fail`, `Pending`|
|> createdAt|string |เวลาที่สร้างคำสั่ง หน่วยมิลลิวินาที|
|> productId|string |รหัสผลิตภัณฑ์|
|> updatedAt|string |เวลาที่อัปเดตคำสั่ง หน่วยมิลลิวินาที|
|> swapOrderValue|string |มูลค่าคำสั่งสวอป ใช้กับ LST Onchain เท่านั้น|
|> estimateRedeemTime|string |เวลาไถ่ถอนโดยประมาณ หน่วยมิลลิวินาที ใช้กับ Onchain เท่านั้น|
|> estimateStakeTime|string |เวลาสเตคโดยประมาณ หน่วยมิลลิวินาที ใช้กับ Onchain เท่านั้น|
