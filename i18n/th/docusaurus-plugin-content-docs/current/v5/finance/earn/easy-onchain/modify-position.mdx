:::info
คีย์ API ต้องมีสิทธิ์ "Earn"
:::

:::note
เฉพาะโพซิชันที่มี `duration` = `Fixed` เท่านั้นที่รองรับการตั้งค่าลงทุนต่อโดยอัตโนมัติ คุณสามารถดูค่า `duration` ได้จากการตอบกลับของ [GET /v5/earn/product?category=OnChain](product-info.mdx)
:::

### คำขอ HTTP
<APIEndpoint method="POST" url="/v5/earn/position/modify" />

### พารามิเตอร์คำขอ {#request-parameters}
| พารามิเตอร์ | จำเป็น | ประเภท | คำอธิบาย|
|:----- |:-------|:-----|------ |
|category|**true**|string|ประเภทผลิตภัณฑ์ ค่าคงที่: `OnChain`|
|productId|**true**|integer|รหัสผลิตภัณฑ์ รับค่าได้จาก [GET /v5/earn/product](product-info.mdx)|
|positionId|**true**|integer|รหัสโพซิชัน รับค่าได้จาก [GET /v5/earn/position](position.mdx)|
|autoReinvest|**true**|integer|สวิตช์การลงทุนต่อโดยอัตโนมัติ `0`: ปิด, `1`: เปิด|

### พารามิเตอร์การตอบกลับ {#response-parameters}
| พารามิเตอร์ | ประเภท | คำอธิบาย|
|:----- |:-----|----- |
|retCode|integer|รหัสที่ส่งกลับ `0` หมายถึงสำเร็จ|
|retMsg|string|ข้อความที่ส่งกลับ เป็นสตริงว่าง `""` เมื่อสำเร็จ|
