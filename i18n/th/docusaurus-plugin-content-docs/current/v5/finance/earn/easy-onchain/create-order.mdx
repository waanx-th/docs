:::info
คีย์ API ต้องมีสิทธิ์ "Earn" และยังไม่รองรับบัญชีแบบ custody ในขณะนี้
:::

:::note
ในช่วงที่ตลาดมีความต้องการกู้ยืมคริปโทเคอร์เรนซีสกุลใดสกุลหนึ่งสูง การไถ่ถอนเงินต้น
อาจเกิดความล่าช้า และคาดว่าจะดำเนินการเสร็จภายใน 48 ชั่วโมง การไถ่ถอนผลิตภัณฑ์แบบออนเชนอาจใช้เวลาหลายวันจึงจะเสร็จสมบูรณ์ เมื่อส่งคำขอไถ่ถอนแล้ว
จะไม่สามารถยกเลิกได้
:::

### คำขอ HTTP
<APIEndpoint method="POST" url="/v5/earn/place-order" />

### พารามิเตอร์คำขอ {#request-parameters}
| พารามิเตอร์ | จำเป็น | ประเภท | คำอธิบาย|
|:----- |:-------|:-----|------ |
|category |**true**| string |`FlexibleSaving`,`OnChain` <br/>**หมายเหตุ**: ปัจจุบันรองรับเฉพาะ flexible savings และ on chain เท่านั้น|
|orderType |**true**| string |`Stake`, `Redeem`|
|accountType |**true**| string |`FUND`, `UNIFIED` โดย Onchain รองรับเฉพาะ FUND|
|amount |**true**| string |<ul><li>จำนวนที่สเตคต้องเป็นไปตาม minStake และ maxStake</li><li>จำนวนทั้งการสเตคและการไถ่ถอนต้องเป็นไปตามข้อกำหนดความละเอียดของทศนิยม</li></ul>|
|coin |**true**| string |ชื่อเหรียญ|
|productId |**true**| string |รหัสผลิตภัณฑ์|
|orderLinkId |**true**| string |รหัสคำสั่งซื้อขายที่กำหนดเอง ใช้เพื่อป้องกันการส่งซ้ำ<ul><li>รองรับความยาวไม่เกิน 36 อักขระ</li><li>ไม่สามารถใช้ orderLinkId เดิมซ้ำได้ภายใน 30 นาที</li></ul>|
|redeemPositionId|false| string |รหัสโพซิชันที่ผู้ใช้ต้องการไถ่ถอน จำเป็นเฉพาะในโหมด Onchain non-LST เท่านั้น|
|toAccountType |false| string |`FUND`, `UNIFIED` โดยโหมด Onchain LST รองรับ `FUND` และ `UNIFIED` (บัญชีย่อยแบบ custodial สำหรับการบริหารความมั่งคั่งส่วนบุคคลรองรับเฉพาะ `UNIFIED`) ส่วนโหมด Onchain non-LST รองรับเฉพาะ `FUND`|
|interestCard|false|Object|การ์ดโบนัสดอกเบี้ย ใช้ได้เฉพาะกับคำสั่ง `Stake` ของ `FlexibleSaving` เท่านั้น รับค่า `awardId` และ `specCode` ได้จาก[ดูรายการคูปอง](./coupons)|
|> awardId|**true**|int64|รหัสการ์ดโบนัสดอกเบี้ยที่ไม่ซ้ำกัน|
|> specCode|**true**|string|รหัสสเปกของการ์ดโบนัสดอกเบี้ย|

### พารามิเตอร์การตอบกลับ {#response-parameters}
| พารามิเตอร์ | ประเภท | คำอธิบาย|
|:----- |:-----|----- |
|orderId|string|รหัสคำสั่งซื้อขาย|
|orderLinkId|string |รหัสอ้างอิงคำสั่งซื้อขาย|
