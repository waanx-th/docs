คุณสามารถดูข้อมูลย้อนหลังได้ 3 เดือน

:::info
คีย์ API ต้องมีสิทธิ์ "Earn"
:::

### คำขอ HTTP
<APIEndpoint method="GET" url="/v5/earn/yield" />

### พารามิเตอร์คำขอ {#request-parameters}
| พารามิเตอร์ | จำเป็น | ประเภท | คำอธิบาย|
|:----- |:-------|:-----|------ |
|category|**true**|string|`FlexibleSaving`,`OnChain`|
| productId   | false    | string    | รหัสผลิตภัณฑ์ **ไม่รองรับเมื่อ `category=OnChain`** การส่งพารามิเตอร์นี้จะทำให้เกิดข้อผิดพลาด                          |
| startTime   | false    | integer  | ประทับเวลาเริ่มต้น (มิลลิวินาที)<ul><li> 1. หากไม่ได้ระบุทั้งสองค่า ค่าเริ่มต้นคือส่งข้อมูล 7 วันล่าสุดกลับมา</li><li>2. หากระบุทั้งสองค่า ผลต่างระหว่าง endTime และ startTime ต้องน้อยกว่าหรือเท่ากับ 7 วัน </li></ul>                                                                                           |
| endTime     | false    | integer  | ประทับเวลาสิ้นสุด (มิลลิวินาที)                                                                                                              |
| limit       | false    | integer  | จำนวนข้อมูลสูงสุดต่อหน้า ช่วงค่า: [1, 100] ค่าเริ่มต้น: 50                                                                            |
| cursor      | false    | string  | เคอร์เซอร์ ใช้ `nextPageCursor` ที่ส่งกลับมาเพื่อค้นหาข้อมูลหน้าถัดไป                                                       |


### พารามิเตอร์การตอบกลับ {#response-parameters}
| พารามิเตอร์ | ประเภท | คำอธิบาย|
|:----- |:-----|----- |
|nextPageCursor |string |ดูพารามิเตอร์คำขอ `cursor` |
| list                    | array  | Object                                                                                                     |
| > productId             | string  | รหัสผลิตภัณฑ์                                                                                                 |
| > coin                  | string | ชื่อเหรียญ: "BTC", "ETH"                                                                                               |
| > id                    | string | คีย์ที่ไม่ซ้ำกัน (รับประกันความไม่ซ้ำภายในผู้ใช้รายเดียวกันเท่านั้น)                                              |
| > amount                | string | จำนวนผลตอบแทน ตัวอย่าง: 10                                                                                                |
| > yieldType             | string | ประเภทผลตอบแทน: `Normal`, `Bonus` (flexible saving รองรับเฉพาะ `Normal`)                                     |
| > distributionMode      | string | ประเภทการจ่าย: `Auto`, `Manual`, `Reinvest`<ul><li>`Auto`: จ่ายอัตโนมัติทุกวัน </li><li>`Manual`: จ่ายเมื่อผู้ใช้ไถ่ถอน </li><li>`Reinvest`: ลงทุนต่อ (ยังไม่เปิดให้ใช้งาน)</li> </ul>                                                          |
| > effectiveStakingAmount| string | จำนวนที่สเตคซึ่งมีผล เช่น 1000.00                                                                    |
| > orderId               | string | UUID ของคำสั่งไถ่ถอน สำหรับ `FlexibleSaving` จะส่งรหัสคำสั่งซื้อขายกลับมาเฉพาะเมื่อ `distribution_mode` เป็น `Manual`                                                                                      |
| > status                | string | สถานะคำสั่ง: `Pending`, `Success`, `Fail`                                                                 |
| > createdAt             | string | เวลาที่สร้างคำสั่งเป็นมิลลิวินาที เช่น 1684738540561                                                   |
