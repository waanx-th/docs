## กฎการจำกัดอัตราการเรียก API สำหรับผู้ใช้ระดับ PRO

:::info การเปลี่ยนแปลงที่กำลังจะเกิดขึ้นสำหรับบัญชี pro
ตั้งแต่ **13 สิงหาคม 2025** WaanX จะเริ่มใช้กรอบการจำกัดอัตราการเรียก API 
ระดับสถาบันรูปแบบใหม่ ซึ่งออกแบบมาเพื่อยกระดับประสิทธิภาพให้ลูกค้าที่เทรดด้วยความถี่สูง 
ระบบใหม่นี้กำหนดเพดานอัตราการเรียกระดับสถาบันแบบรวมศูนย์ พร้อมการตั้งค่าแยกตาม UID 
ได้อย่างยืดหยุ่น จึงเพิ่มประสิทธิภาพและความสามารถในการขยายขนาด โปรดดู[ประกาศ](https://waanx.com/en/gb/announcements)สำหรับข้อมูลเพิ่มเติม
:::

:::tip คำแนะนำเกี่ยวกับการจำกัดอัตราการเรียก API
- บัญชีย่อยที่มีอยู่ทั้งหมดยังคงใช้การจำกัดอัตราการเรียก API เดิมของตน
- การจำกัดอัตราการเรียก API ค่าเริ่มต้นของบัญชีย่อยใหม่จะไม่ถูกนับรวมในการจำกัดอัตราการเรียก API ระดับสถาบัน 
- การจำกัดอัตราการเรียก API ค่าเริ่มต้นของบัญชีย่อยใหม่คือ 20/s สำหรับสปอต
- หากใช้เกินการจำกัดอัตราการเรียก API รวมระดับสถาบัน คุณต้องลดการจำกัดอัตราการเรียก API ของบัญชีหนึ่งบัญชีหรือหลายบัญชีก่อน เมื่อการจำกัดอัตราการเรียก API น้อยกว่าการจำกัดอัตราการเรียก API รวมระดับสถาบันแล้ว คุณจึงจะเพิ่มการจำกัดอัตราการเรียก API ของบัญชีได้
:::
