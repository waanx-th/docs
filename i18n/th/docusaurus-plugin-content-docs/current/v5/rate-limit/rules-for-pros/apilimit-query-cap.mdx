> การจำกัดอัตราการเรียก API: 50 คำขอต่อวินาที

:::info
* ใช้สำหรับเรียกดูปริมาณการใช้และเพดานของการจำกัดอัตราการเรียกรวมทั้งหมดของสถาบันของคุณ
* ทั้ง UID หลักและ UID ย่อยสามารถเรียกใช้เอนด์พอยต์นี้ได้ แต่ UID หลักจะเห็นได้เฉพาะการจำกัดอัตราการเรียกของบัญชีย่อยที่อยู่ภายใต้ตนเองเท่านั้น ไม่เห็นบัญชีย่อยของ UID หลักอื่น
:::

### คำขอ HTTP
<APIEndpoint method="GET" url="/v5/apilimit/query-cap" />

### พารามิเตอร์คำขอ {#request-parameters}
ไม่มี

### พารามิเตอร์การตอบกลับ {#response-parameters}
| พารามิเตอร์ | ประเภท | คำอธิบาย|
|:----- |:-----|----- |
|list |array |อ็อบเจกต์|
|> [bizType](/v5/enum#biztype) |string|ประเภทธุรกิจ |
|> totalRate |integer|ปริมาณการใช้การจำกัดอัตราการเรียก API รวมของบัญชีย่อยทั้งหมดและบัญชีหลัก |
|> insCap |integer|การจำกัดอัตราการเรียก API ต่อวินาทีในระดับสถาบัน (ขึ้นอยู่กับระดับ pro ของคุณ) |
|> uidCap |integer|การจำกัดอัตราการเรียก API ต่อวินาทีในระดับ UID |
