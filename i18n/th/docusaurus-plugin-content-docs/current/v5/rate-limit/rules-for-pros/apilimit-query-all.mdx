> การจำกัดอัตราการเรียก API: 50 คำขอต่อวินาที

:::info
* ใช้สำหรับเรียกดูการจำกัดอัตราการเรียกในระดับ UID ทั้งหมดของคุณ รวมถึงบัญชีหลักและบัญชีย่อยทั้งหมด
:::

### คำขอ HTTP
<APIEndpoint method="GET" url="/v5/apilimit/query-all" />

### พารามิเตอร์คำขอ {#request-parameters}
| พารามิเตอร์ | จำเป็น | ประเภท | คำอธิบาย|
|:----- |:-------|:-----|------ |
|limit |false |string |จำนวนข้อมูลสูงสุดต่อหนึ่งหน้า [`1`, `1000`] ค่าเริ่มต้น: `1000`|
|cursor |false |string |เคอร์เซอร์ ใช้โทเค็น `nextPageCursor` จากการตอบกลับเพื่อดึงข้อมูลหน้าถัดไปของชุดผลลัพธ์|
|uids |false|string|UID หลายรายการจากบัญชีหลักที่แตกต่างกัน คั่นด้วยเครื่องหมายจุลภาค ค่าเริ่มต้นจะคืนค่าบัญชีหลักและบัญชีย่อยทั้งหมด|

### พารามิเตอร์การตอบกลับ {#response-parameters}
| พารามิเตอร์ | ประเภท | คำอธิบาย|
|:----- |:-----|----- |
|nextPageCursor |string |ดูพารามิเตอร์คำขอ `cursor`|
|list |array |อ็อบเจกต์|
|> uids |string|UID หลายรายการคั่นด้วยเครื่องหมายจุลภาค|
|> [bizType](/v5/enum#biztype) |string|ประเภทธุรกิจ |
|> rate |integer|การจำกัดอัตราการเรียก API ต่อวินาที |
