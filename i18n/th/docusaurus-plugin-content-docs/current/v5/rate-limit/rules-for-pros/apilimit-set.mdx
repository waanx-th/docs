> การจำกัดอัตราการเรียก API: 50 คำขอต่อวินาที

:::info
* หาก UID ที่เรียกใช้เอนด์พอยต์นี้เป็นบัญชีหลัก UID ที่ส่งเข้ามาในพารามิเตอร์ `uids` ต้องเป็นบัญชีย่อยของบัญชีหลักนั้น
* หาก UID ที่เรียกใช้เอนด์พอยต์นี้ไม่ใช่บัญชีหลัก UID ที่ส่งเข้ามาในพารามิเตอร์ `uids` ต้องเป็น UID ของบัญชีย่อยที่เรียกใช้เอนด์พอยต์นี้เท่านั้น
* มีเพียงผู้ใช้ประเภทสถาบันเท่านั้นที่สามารถเรียกใช้เอนด์พอยต์นี้ได้
:::

### คำขอ HTTP
<APIEndpoint method="POST" url="/v5/apilimit/set" />

### พารามิเตอร์คำขอ {#request-parameters}
| พารามิเตอร์ | จำเป็น | ประเภท | คำอธิบาย|
|:----- |:-------|:-----|------ |
|list |**true**|array |อ็อบเจกต์|
|> uids |**true**|string|UID หลายรายการคั่นด้วยเครื่องหมายจุลภาค|
|> [bizType](/v5/enum#biztype) |**true**|string|ประเภทธุรกิจ |
|> rate |**true**|integer|การจำกัดอัตราการเรียก API ต่อวินาที |

### พารามิเตอร์การตอบกลับ {#response-parameters}
| พารามิเตอร์ | ประเภท | คำอธิบาย|
|:----- |:-----|----- |
|list |array |อ็อบเจกต์|
|> uids |string|UID หลายรายการคั่นด้วยเครื่องหมายจุลภาค|
|> [bizType](/v5/enum#biztype) |string|ประเภทธุรกิจ |
|> rate |integer|การจำกัดอัตราการเรียก API ต่อวินาที |
|> success |boolean| คำขอสำเร็จหรือไม่|
|> [msg](/v5/enum#msg) |string|ข้อความผลลัพธ์ |
