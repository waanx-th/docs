## สมัครเป็น Master Trader
โปรดไป[ที่นี่](https://waanx.com)เพื่อสมัครเป็น Master Trader

## สร้างคีย์ API
"Spot - Trade" เป็นสิทธิ์ที่จำเป็นสำหรับคำสั่งซื้อขายแบบ Copy Trading

## ทำความเข้าใจขอบเขตการใช้งาน
บัญชี copy trading สามารถเทรดได้เฉพาะสัญลักษณ์คู่เทรดสปอตเท่านั้น โปรด
ตรวจสอบ [ข้อมูลเครื่องมือการเทรด](./market/instrument#) สำหรับสัญลักษณ์คู่เทรดที่เทรดได้

## สร้างคำสั่งซื้อขายแบบ Copy Trading
ใช้เอนด์พอยต์ V5 [สร้างคำสั่งซื้อขาย](./order/create-order) เพื่อสร้างคำสั่งซื้อขายแบบ Copy Trading

```http
POST /v5/order/create HTTP/1.1
Host: api.waanx.com
X-BAPI-SIGN: XXXXXX
X-BAPI-API-KEY: xxxxxxxxxxxxxxxxxx
X-BAPI-TIMESTAMP: 1698376189371
X-BAPI-RECV-WINDOW: 5000
Content-Type: application/json
Content-Length: 207

{
    "symbol": "BTCUSDT",
    "side": "Buy",
    "orderType": "Limit",
    "category": "spot",
    "qty": "0.1",
    "price": "29000",
    "timeInForce": "GTC"
}
```
